## V38 — 불필요한 안내 문구 제거

- **V38 편집 스타일:** 오늘·사전·마이·설정·새 감정 만들기의 반복적인 작은 회색 안내 문구와 부제목을 제거. 마이 탭은 '나의 지도' 타이틀·전체/30일 버튼·지도·감정별 기록 데이터만 남겨 감정에 집중. 오늘의 감정 선택 전 문구와 메모 placeholder, 사전 프라이버시 중복 라벨/안내, 설정의 설명 문단, 섞는 법 안내와 선택형 라벨 등의 보조 카피 제거. 화면은 여백을 재정렬해 불필요한 빈 칸 없이 담백하게 유지. 기록 날짜, 현재 감정 선택, 혼합 방울 수, 지도 분석 수치, 만료 알림, 샘플 여부, 빈 기록 안내 등 필요한 상태 정보는 보존. 유통기한 설명의 ARIA 라이브 문구는 시각적으로 숨기되 화면 읽기 기능은 유지. 기존 로컬 기록·디자인 팔레트·슬라이더·핀치 모션 변경 없음.
- **V37 마이페이지:** 지도를 **사전 탭에서 분리하고 별도의 '마이' 탭**으로 이동. 사전은 나만의 감정을 만들고 관리하는 본래 역할로 복구. 새로운 마이 탭은 420×610 좌표계의 감정 지도를 **화면 좌우 끝까지 펼치고 세로 높이를 화면의 약 76%** 사용. 감정 원 사이 여유를 늘리고 중심으로 쏠리는 힘을 약화시킨 넓은 레이아웃으로 재배치하되, 자주 함께 등장하는 감정의 연결선은 여전히 두껍고 또렷하게 표시. 서로 겹치지 않도록 충돌 완화 후 세로 방향으로 한 번 더 넓힘. 전체/30일 선택과 감정별 터치 분석, 데모 링크, 기존 유통기한/기록/구슬 색/핀치 모션은 유지. 5개 상단 탭은 320px 너비에서도 맞도록 간격 조정.
- **V36 감정 지도:** 개인의 모든 기록으로 만드는 감정 네트워크를 최초 구현. 하루 기록에 등장한 감정은 감정별 등장 빈도를 **원 크기**로 표시하며, 같은 날 함께 등장한 각 감정쌍의 누적 횟수를 **연결선 두께·선명도**로 반영. 함께 자주 등장하는 감정이 가까워지도록 배치하고, 원을 누르면 해당 감정 및 연관선만 강조하며 실제 등장 횟수와 가장 자주 함께 나온 감정을 보여줌. 전체 기간 / 최근 30일 전환, 기록이 없을 때는 별도 메모리 샘플 지도 링크 제공. 기본 8색 및 사용자가 만든 감정도 집계. 입력한 날짜별 서로 다른 감정을 1회씩 세며 감정 상태의 좋고 나쁨을 평가하거나 진단하지 않음. 노드가 너무 많으면 주요 16개, 연결선이 너무 많으면 강한 50개만 시각화해 모바일에서 읽기 쉽게 유지. SVG 키보드/터치 조작과 비공개 로컬 집계. 기존 감정 사전은 지도 아래 유지.
- **V35 슬라이더 수정:** 실제 iOS 스크린샷에서 기본 파란색 range가 노출되고 레일이 짧으며 선택 시간 라벨이 한쪽에 붙는 문제 확인. 가로 폭 전체에 네 점을 정확히 0·1/3·2/3·1 지점으로 배치하고 숫자 라벨 중심과 일치시킴. 각 점은 20px 동일 슬롯 안에 그려 선택점이 커져도 위치가 변하지 않으며, 얇은 2px 녹회색 레일과 1개 선택점만 강조. 실제 range 입력은 투명하게 유지(드래그/탭/키보드), 네 점·라벨만 커스텀 표시. CSS 캐시/배포가 늦어도 파란 슬라이더로 퇴행하지 않게 HTML에 핵심 스타일을 동봉. 안내 문장 간소화. 320~520px 반응형·양끝 탭 Chromium 테스트 통과. 실제 iPhone Safari 검증 필요.
- **V34 코펜하겐 모던 슬라이더:** 드롭다운을 제거하고 **1시간 · 24시간 · 3일 · 7일**, 총 네 곳에서 딱 멈추는 `range` 슬라이더로 교체. 바 위 네 개의 작은 원, 가는 레일, 현재 지점만 짙은 그린, 옅은 아이보리 바탕, 절제된 타이포그래피를 사용. 손가락 드래그·막대 탭·키보드 화살표 지원, 움직이는 동안 실시간 라벨 반영, 조작 확정 시에만 로컬 설정 저장. 기존 유통기한 저장 시간값/기록/메모/아카이브 그대로 유지.
- **V33 기록 유통기한:** **설정**에서 유통기한을 **1시간 / 24시간(기본) / 3일 / 7일** 중 선택. V32의 '제한 없음'과 '30일' 제거. 이전에 이 두 기간을 저장한 경우 24시간으로 자동 정규화(기존 감정 기록과 메모는 보존). 최초 저장 시각부터 계산해 기한이 지난 기록은 읽기 전용으로만 표시. 감정·메모 수정은 기한 안에서 가능하고 `createdAt`은 수정해도 초기화되지 않음. 기존 기록 중 최초 저장 시간이 없는 경우 해당 날짜 **23:59:59.999(현지 시간)**을 기준으로 계산. 변경된 유통기한은 과거 기록에도 적용. 개인 규칙이므로 1시간에서 7일로 바꾸면 아직 7일이 지나지 않은 기록은 다시 수정 가능. 데모 모드는 기록과 설정을 저장하지 않음.
- **V27 기본 감정 고정 8색:** 참고 이미지의 8가지 배경색·숫자색 조합을 **기쁨/평온/슬픔/불안/분노/놀람/혐오/기대** 각각에 1:1 매핑. 기본 감정 수는 그대로 8개이며 12색 데모 팔레트는 제거. **실제 오늘 기록/사전/아카이브의 기본 감정색도 동일하게 변경**. 기록은 감정 ID로 저장되므로 기존 데이터 내용은 그대로지만 이전 기록의 표시색은 새 팔레트로 바뀜. 데모는 정확히 8색, 단색 70%/다중감정 30%; 그라데이션은 미리 정한 8가지 기본 감정 조합만 사용. 구슬 테두리 없음, 굵은 날짜 숫자, 큰 1개월 구슬 및 기존 연속 핀치는 유지
- **V31 연감 모션:** 6개월 ↔ 1년 전환 시 기존 최대 76개 구슬만 이동하고 일부 날짜가 갑자기 나타나던 방식을 개선. **이전·다음 달력 포스터 전체를 GPU opacity 레이어로 겹쳐 전환**하고 손가락 주변에서 중요한 동일 날짜 구슬만 모바일 최대 **48개 고스트 복사본**으로 실제 위치와 크기를 이어 이동. 손을 놓으면 화면은 바로 새 레이아웃으로 전환하면서 약 **230ms** 동안 기존/새 포스터 페이드와 구슬 이동이 자연스럽게 마무리. 연속 핀치·한 손가락 스와이프·마우스 드래그에서도 해당 전환 적용. 1↔3↔6개월 기존 모션, 저장 형식, 구슬 디자인은 유지. 실제 iPhone 성능은 별도 측정 필요.
- **오늘 기록:** 기본/개인 감정 1~4개 선택, 선택적 메모, 로컬 저장
- **V30 좌우 대칭:** 4감정 구슬의 120° 바깥 링 시작 각도를 -90° → **-60°**로 회전. 맨 위 색상 조각은 정확히 12시 축을 중심으로 좌우 대칭이며, 아래쪽 분할선은 6시 수직 방향으로 내려감. 감정 순서, 링 두께 62% 내부 지름, 1·2·3감정 구슬, 날짜 숫자·기존 기록·핀치 이동은 모두 그대로.
- **V29 동심원 구슬:** 1감정은 단색. 2감정은 첫 감정 단색 내부원+두 번째 감정 바깥 링. 3감정은 첫 감정 단색 내부원+나머지 2감정을 반반 나눈 바깥 링. 4감정은 **첫 감정 단색 내부원+나머지 3감정을 각각 120°씩 나눈 바깥 링**. 내부원 지름을 69% → **62%**로 줄여 바깥 링을 약 23% 더 두껍게. 오늘의 큰 구슬·달력·저장 이동·데모는 같은 렌더러를 사용. 기존 8가지 기본 감정과 기록 구조는 변경 없음.
- **감정 만들기:** V8의 담백한 **색상 원 버튼**은 그대로 유지. 길게 누르기는 첫 추가 방울까지 780ms, 이후 850ms마다 1개씩 미세 조정. 각 방울은 약 2.8초에 걸쳐 혼합 박스의 바깥쪽까지 더 넓고 천천히 번짐. 섞으면 기존 단일 Canvas에서 중앙으로 응집. 완료 후 혼합 비율 공개
- **나의 사전:** 새로운 단색 감정에 이름과 정의를 선택적으로 붙여 개인 사전에 저장, 일기에 재사용
- **달력 저장:** 구슬이 회전·축소하며 오늘 날짜로 이동하는 애니메이션
- **접근성:** OS에서 Reduce Motion 설정 시 이동 애니메이션 축약

### V38 달력
- **숫자를 색 위에:** 날짜를 원색 감정 구슬 위에 직접 표시하고, 요일(일–토)을 맨 윗줄에 둠
- **기간 확대·축소:** 1개월 → 3개월 → 6개월 → 1년. 전 기간을 동일한 감정 구슬 포스터 레이아웃으로 통일하며, 각 월의 날짜를 7/3/2/1열로 펼쳐 담음

- **시각 언어:** 아이보리 바탕, 절제된 타이포그래피와 여백. 전 기간에서 지그재그 배열과 숫자 날짜 구슬. 연도는 크고 가볍게, 월은 굵게, 연월 사이 슬래시 없이 여백으로 구분
- **유지:** 날짜 탭 시 기록 상세 보기, 저장 시 날짜 구슬까지 이동, 기존 데이터 구조

[**V8 WebGL2 전환 설계안**](./docs/V8_SHADER_TRANSITION.md) — 단색 테두리 제거, 감정별 색상을 따르는 위치별 후광, 동일한 광원 이동, 정적 달력 렌더링 및 Safari fallback. ****V13 원색 디자인이 기본이고, 발광 WebGL2 V8.2는 비교·연구용으로만 유지**합니다. 실제 iPhone Safari 검증은 아직 진행 전입니다.**

## 개발 구조

- `index.html` — 화면 및 의미 구조
- `styles.css` — 모바일 UI, 구슬 및 저장 애니메이션 스타일
- `app.js` — 상태, OKLab 혼합, 감정 구슬 렌더링, Canvas 방울, 월간 기록
- `docs/V2_SPEC.md` — 요구사항, 데이터 모델, 수용 기준, 알려진 한계

별도 빌드 단계 없이 정적 호스팅에서 동작합니다. GitHub Pages는 `main` 브랜치의 루트 폴더를 배포하도록 설정합니다.

## 개인정보 및 미구현 기능

**현재 버전은 로그인이나 서버가 없으며 감정과 메모가 해당 브라우저의 localStorage에만 저장됩니다.** 웹사이트 데이터 삭제 시 사라질 수 있습니다. GitHub Pages에 게시된 것은 *앱의 코드*이며 *사용자의 감정 데이터*가 아닙니다.

Public 감정 공유, 감정 유사도 검색, 알림, 클라우드 백업은 후속 개발 대상입니다. 아카이브 핀치 확대·축소, 수정 유통기한, 개인 감정 지도는 현재 구현됐습니다. 기본 감정의 이름과 **현재 V4 팔레트는 디자인 테스트용**이며 심리학적 최종 모델이 아닙니다. 기존의 기본 감정 기록은 날짜와 메모가 유지되지만 새 팔레트로 다시 표시됩니다. 직접 만든 감정의 저장 색상은 변경하지 않습니다.
