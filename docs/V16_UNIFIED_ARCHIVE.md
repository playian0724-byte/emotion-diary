요일 행을 제거하고 날짜 숫자를 색깔 구슬에 올려 둠. 기록 없는 날은 아주 옅은 회색 원. 각 월 그룹의 홀짝 열 또는 홀짝 월의 세로 위치를 어긋나게 해서 구슬이 쌓인 형태를 만듦.

## 헤더 및 UI
- 기존 `2026 / 10`, `2026 / 10–12`와 같은 슬래시 제거.
- 연도는 크게, 얇은 무게로. 월 또는 월 범위는 굵게, 작게. 사이의 여백으로 구분.
- 연간의 연도 숫자와 12개 월 볼드 숫자 라벨은 그대로 유지.
- 확대·축소 버튼, 드래그 안내 없음. 핀치·드래그 조작 유지.
- `?view=month`, `?view=quarter`, `?view=half`, `?view=year`로 단계별 직행 가능.
