# V47: emotion product page, dictionary navigation and calendar polish

The Dictionary no longer creates emotions. Creation is via Today's Emotion lab. Every dictionary object card opens a standalone page styled after the supplied product detail reference: a single smaller orb in a neutral stage (without image thumbnails or gallery arrows) and saved name, hex, definition, component percentages, creation date, privacy, and optional use-today action. Existing gyeol-v2 records are untouched.

Month markers are pale-grey circular discs matching bead size. Numeric daynum nodes are removed from bead HTML so they cannot appear during pinch/zoom ghost rendering. A double-tapped/clicked bead is marked inspected and gets a dark outline, persisting after the popup closes. The one-month date caption remains below its bead. No changed emotion colors, data storage, pinch definitions or mixing mechanics.

Static JS syntax and DOM reference checks performed. Physical iPhone Safari validation remains recommended.
