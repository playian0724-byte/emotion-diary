# 결. V39 — 기존 웹앱의 UI만 살짝 정돈

## 기준

사용자가 제공한 모바일 UI 레퍼런스의 **굵고 선명한 글씨·단정한 버튼·큰 여백·따뜻한 종이 느낌**만 차용한다. 새로운 앱 시안이나 화면을 만든 것이 아니다.

## 바뀐 부분

- 전체 배경을 순백 아닌 **아주 연한 크림** (`--paper: #faf8f2`; 바깥 배경 `#f2eee7`)으로 변경
- 기존 iOS 시스템 한글/라틴 산세리프 유지, 글자 굵기·자간·계층만 개선
- 화면 제목은 큰 굵은 검정 타입, 소제목도 대비가 분명한 타입으로 정리
- 상단 5개 탭의 **배치 그대로**, 현재 탭만 옅은 베이지 칩으로 표시
- 기존 4열 감정 선택 버튼, 메모 카드, 큰 저장 버튼, 기록 탐색 버튼, 사전 카드, 유통기한 카드에 따뜻한 뉴트럴톤과 둥근 모서리 적용
- 기존 전체 폭 감정 지도는 **좌표/노드 색/연결선/크기 모두 그대로**, 배경 종이색만 따뜻하게
- 컬러/광택/텍스처가 있는 기존 구슬에는 어떤 CSS나 JS 수정도 적용하지 않음

## 절대 바꾸지 않은 부분
- 상단 메뉴 탭 위치 및 순서
- 큰 구슬 및 8가지 기본 감정 구슬 색상과 동심원 규칙
- 오늘 감정 선택 **4열 그리드**
- 기록 달력, 1/3/6/12개월 핀치 줌, 감정 지도 물리 배치
- 직접 만든 감정, 수정 유통기한(1시간/24시간/3일/7일), 저장 데이터 키 `gyeol-v2`
- 데모 동작 및 개인 기록 보호
