# 결. V7 — 내부 광원과 동기화된 Shimmer / Halo

상태: GitHub 코드 업데이트 완료. 실제 iPhone Safari에서 시각 및 성능 검증 필요.

## V6의 문제
V6는 Canvas로 구슬 텍스처를 한 번 만들고 CSS로 전체 밝기를 약 4.5% 가감했다. 그래서 안쪽에서 실제 빛이 움직이는 모습이 아니라 구슬이 통째로 조금 밝아지는 인상을 주었다. 고정된 box-shadow 역시 그 빛과 함께 움직이지 않았다.

## V7의 수정
1. **움직이는 내부 광원:** 구슬 안쪽에 넓고 흐린 발광 영역을 추가한다. 7.6초 동안 약 10px 내외를 천천히 이동하고 빛의 강도가 바뀐다.
2. **Shimmer:** 작은 확산 반사 두 개가 내부 광원과 같은 경로를 따라 움직이며 밝기가 오르내린다. 별이나 반짝이 아이콘처럼 날카로운 점광원은 사용하지 않는다.
3. **이동하는 후광:** 구슬의 바깥 shadow도 동일한 7.6초 애니메이션과 위상에서 왼쪽 아래 → 오른쪽 위 → 오른쪽 아래 → 시작점으로 이동한다.
4. **색 일치:** 후광은 감정 구슬 색상을 바탕으로 만든 rgba 색이다. 이전보다 약간 강하게 설정해 밝은 오프화이트 배경에서도 미세하게 관찰된다.
5. **달력:** 작은 구슬은 움직이는 빛과 후광을 추가하지 않는다. 깨끗한 정적 아카이브를 유지한다.
6. **저장 애니메이션:** 달력으로 날아가는 구슬은 빛 애니메이션을 잠시 중단하여 궤적이 산만해지지 않는다.
7. **접근성:** Reduce Motion 설정 시 내부 광원과 Shimmer, 후광 이동을 모두 정지시킨다.

## 디자인 원칙
- 구슬의 감정색과 가장자리의 동일 색 계열 유지. 다른 색 림이나 흰색 stroke 금지.
- 빛은 표면의 스티커가 아니라 유리 아래의 작은 랜턴처럼 흐려지고 퍼져야 한다.
- 화면 전체의 색채 효과는 구슬에만 집중하고 문구와 버튼은 코펜하겐풍 미니멀 UI 유지.
- 반짝이는 물체보다 부드러운 내부 발광 오브제에 가깝게.

## 기술적 구현
- Canvas 기반 V6 색유리 표면 렌더링은 그대로 사용한다.
- styles.css의 ::before 레이어는 넓은 내부 발광, ::after 레이어는 움직이는 작은 shimmer로 사용한다.
- box-shadow의 방향/반경/알파를 CSS keyframe으로 움직여 외부 halo가 내부 광원에 동조한다.
- 자바스크립트에서 --orb-halo, --orb-halo-strong 변수를 각 구슬의 혼합 색상을 바탕으로 생성한다.
- 주기 7.6초, 0/33/66/100% 키프레임으로 전부 같은 궤적을 따른다.
- 기존 저장 키 gyeol-v2, 혼합 비율, 그라데이션 배치, 메모와 기록 스키마는 유지한다.

## Safari 확인할 것
- [ ] 구슬이 전체적으로 밝아졌다 어두워지는 게 아니라, 내부에서 밝은 지점이 이동하는지
- [ ] Shimmer의 위치 이동이 눈에 보이면서도 별도 흰 스티커처럼 뜨지 않는지
- [ ] 구슬 밖 부드러운 색빛이 내부 이동과 같은 방향으로 이동하는지
- [ ] 혼합 완료 구슬에도 같은 재질과 움직임이 적용되는지
- [ ] 달력 작은 구슬은 조용히 정지해 있는지
- [ ] 감정 선택과 저장 애니메이션이 원활하게 동작하는지
- [ ] 기기에 저장된 날짜/메모/개인 감정이 유지되는지
- [ ] iOS Reduce Motion 설정 시 반복 움직임이 멈추는지

## 한계
실제 물리적인 투명 유리 속 전구·체적 산란을 3D로 계산하지는 않는다. Canvas 텍스처와 CSS 확산광 레이어를 조합한 시각적 근사 방식이다. 실제 iPhone 렌더 결과 및 움직임은 사용자 테스트로 확인한다.
