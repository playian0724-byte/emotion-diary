# 결. V23 — 단색 70% / 그라데이션 30% 데모 연감

날짜별 구슬 애니메이션을 실제 감정 기록 없이도 테스트할 수 있는 전용 모드.

## 데모 링크

https://playian0724-byte.github.io/emotion-diary/?v=23&demo=1&view=year

## 데이터 구성

- 2026년 1월 1일~현재 날짜에 구슬을 매일 하나씩 표시하고, 미래 날짜는 비움.
- 2026년 10월 11일 기준 **284개 구슬**: 단색 199개(약 70.1%), 그라데이션 85개(약 29.9%).
- 단색은 앱의 8가지 선명한 기본 감정 색상 중 하나.
- 그라데이션은 2~3개의 기본 감정색을 혼합. 이미 디자인 시스템에 구현된 `paintOrb` 렌더러를 사용.
- 그라데이션의 조합을 15가지 팔레트로 제한하고 캐시를 재사용하므로 대량의 임의 조합을 렌더링하는 부담을 억제.
- 시드가 고정된 의사난수 생성기를 사용해 새로고침해도 같은 날짜에 같은 색이 나타남. 매년 시작일~오늘까지 기간 계산 가능.

## 개인정보·저장 안전성

- `demo=1`이 있을 때만 별도 메모리 객체 `demoRecords`를 생성하고 달력에 표시.
- 실제 `db.records` 값은 수정하지 않음. `saveDB` 또한 이 모드에서 실행되지 않으므로 사용자 로컬 기록에 **쓰기 없음**.
- 화면에 샘플 기록 안내와 `실제 기록 보기` 링크 표시.
- 데모에서 나와 `?v=23&view=year`로 들어가면 실제 감정 기록만 표시.
