# 결. V11 — 스포이드와 물감 확산 복구

**기본 화면:** V11 (원색 감정 구슬 및 단일 Canvas 응집 유지)

## V10에서 사라졌던 것과 복구
V10에서 같은 감정색 방울 여러 개를 평균 위치 하나로 합치면서, 방울별 시간차에 따라 물 위로 퍼지는 표현이 사라졌다. V11은 **개별 방울마다 위치, 추가 시간, 색상, 확산 반경을 추적**한다.

- 감정 버튼의 색상 원을 **컬러 스포이드 아이콘**으로 교체. 기존 탭 1방울, 롱프레스 연속 추가, 개수 표시는 유지.
- 물 위에서 각 방울의 위치에 짧게 등장하는 **스포이드 투하 애니메이션**을 추가. 감정 버튼의 색을 그대로 보여준다.
- 스포이드가 물에 방울을 떨어뜨리는 약 245ms 뒤부터 작은 염료 점이 생기고, 약 0.95초간 원형으로 넓게 확산. 첫 1.15초간 옅은 동심원 파문을 표시.
- 같은 색이더라도 각각 별도 위치에서 퍼지고 부드럽게 겹친다. 색을 평균 위치로 합치는 그룹화를 제거.
- **섞기**를 누르면 기존 V10의 같은 Canvas 픽셀 필드가 중앙으로 수축하며 색이 혼합되고, 최종 원색 구슬이 완성된다. 별도 구슬 팝업이나 fade-in은 없다.
- `prefers-reduced-motion` 사용자는 스포이드 모션과 낙하 지연을 생략한다.

## 유지
- 감정 방울 최대 36개 / 최대 8가지 원색.
- 완료 후 감정 비율, 이름/정의 저장, 오늘 사용 기능.
- 기존 `gyeol-v2` 저장 키/기록/사전 데이터 유지.
- 이전 광원 WebGL2 실험은 여전히 opt-in.
