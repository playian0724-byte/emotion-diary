# 결. — V2 구현 명세서

작성: 2026-10-10 · 상태: 웹 프로토타입 V2

## 1. 제품의 목적
**하루 5~10초 동안 자신의 감정을 밖으로 꺼내어 바라보고, 기록이 쌓이면서 자신을 조금 더 이해하게 하는 도구.**

- 기록은 강제하지 않는다. 메모, 감정 이름, 정의는 모두 선택이다.
- 감정에 좋고 나쁨의 점수를 매기지 않는다.
- 일반 기록과 감정 창작은 서로 다른 흐름이다.
- 사용자에게 심리 진단을 제공하지 않는다.

## 2. 정보 구조
| 화면 | 주요 목적 | 주요 액션 |
|---|---|---|
| 오늘 | 오늘 느낀 감정 1~4개 선택 | 선택, 해제, 선택적 메모, 저장 |
| 기록 | 월별 구슬 아카이브 | 이전/다음 달, 날짜 열기 |
| 사전 | 자신이 만든 감정 관리 | 감정 목록, 오늘 사용하기 |
| 새 감정 만들기 | 기존 감정으로 설명하기 어려운 마음 표현 | 물감 떨어뜨리기, 비율 조절, 섞기, 이름·정의, 저장 |

## 3. 오늘 기록: ‘공존’의 그라데이션
- 선택 가능한 감정: 기본 감정 + 이전에 정의한 개인 감정 + 샘플 감정.
- 탭 1회: 해당 감정 선택, 재탭: 선택 해제. 최대 4개.
- 단 하나만 선택해도 기록 가능.
- 여러 감정을 선택해도 **비율을 묻지 않는다**.
- 구슬 렌더 규칙:
  - 1개 → 단색.
  - 2개 → 서로 맞은편의 두 색 사이의 부드러운 그라데이션.
  - 3개 → 구슬을 내접원으로 갖는 정삼각형의 세 꼭짓점에 색을 배치, 내부에서 부드럽게 보간.
  - 4개 → 구슬을 내접원으로 갖는 정사각형의 네 꼭짓점에 색을 배치, 내부에서 부드럽게 보간.
- 자동 정렬: 색상환상의 색상 순으로 고정 배치. 선택 순서는 결과에 영향을 주지 않는다.
- 위치별 영향력은 균등하며 3~4개 선택 시 중앙에서 색이 자연스럽게 만난다.
- 이 과정으로 만들어진 중앙의 중간색은 독립된 감정이 **아니다**.

## 4. 감정 만들기: ‘혼합’의 단색
진입: 오늘 화면의 ‘새 감정 만들기’, 또는 사전의 ‘나만의 감정 만들기’.

1. 넓은 사각형의 자유로운 수면 영역을 보여준다. 이는 구슬과 별도의 표현 공간이다.
2. 기본 감정 탭 1회 → 색 한 방울이 수면 위로 번진다. 탭 횟수가 혼합 재료의 상대적인 양이다.
3. 기본 감정을 **길게 누르면** 처음 1방울 입력 후 약 470ms부터 약 230ms 간격으로 추가된다.
4. 최대 36방울. ‘한 방울 취소’, ‘다시 만들기’ 제공.
5. 섞기 전: 방울 수는 보여줄 수 있지만 정확한 퍼센트는 숨긴다.
6. ‘섞기’ → 번진 수면이 흐려지며 하나의 **단색** 구슬이 나타난다.
7. 섞기 후: 감정별 혼합 비율을 공개한다.
8. 이름과 정의는 선택. 미입력 시 ‘이름 미정’으로 저장하여 나중에도 구별할 수 있다.
9. ‘사전에 저장’: 개인 감정으로 보관. ‘오늘 사용하기’: 보관 후 오늘 선택에 추가.

V2의 수면 번짐은 **Canvas 기반 시각적 근사 애니메이션**이며 실제 유체역학 시뮬레이션이 아니다.

## 5. 색상 계산
- 기본 감정의 색은 **초기 디자인용 임시 팔레트**이며 심리학적으로 확정된 대응표가 아니다.
- 혼합색 계산에는 OKLab 보간을 사용하고, 출력에 맞게 sRGB로 변환한다.
- 혼합 전 상대비: 기쁨 ×2, 평온 ×1 → 혼합 후 기쁨 66.7%, 평온 33.3%.
- 탭 횟수 2:1과 20:10은 같은 혼합색과 같은 상대비를 의미한다.
- 기록용 다색 구슬은 단색 평균을 취하지 않는다. 꼭짓점별 색상을 공간 보간해 각 색을 남긴다.
- 같은 감정 조합은 선택 순서에 상관없이 일관된 시각 결과를 만든다.

## 6. 저장 애니메이션
**의미:** 지금 바라보는 마음이 시간 속의 기록으로 들어가는 순간.

1. 저장 요청 시 선택 감정 및 메모를 먼저 로컬에 반영한다.
2. 중앙 구슬과 같은 색의 비행용 복제 구슬을 생성한다.
3. 화면을 달력으로 전환하여 이번 달의 오늘 날짜 칸을 찾는다.
4. 구슬이 약 1.05초간 회전(약 1.2바퀴), 축소, 곡선에 가까운 경로로 해당 날짜의 원에 도착한다.
5. 도착 구슬에 짧은 탄성 효과를 주고 완료 메시지를 표시한다.
6. 운영체제에서 Reduce Motion을 사용하면 긴 모션을 생략한다.

이미 저장한 날짜에 재저장하면 해당 날짜의 기록을 덮어쓴다. V2에는 삭제/복구 이력이 없다.

## 7. 저장 및 개인정보
- GitHub Pages에서 작동하는 정적 클라이언트 웹앱.
- localStorage 키: `gyeol-v2`.
- 기존 V1의 `gyeolRecords` 기록이 있으면 최초 실행 시 기본 감정 ID로 옮긴다.
- 데이터 모델: `records[YYYY-MM-DD] = { emotions: [id], note, createdAt }`.
- 개인 감정: `{ id, name, color, definition, components:[{id,ratio}], visibility:'private', createdAt }`.
- **V2의 모든 실제 기록 및 나만의 감정은 기기 브라우저 안에만 저장된다.**
- Public 공유/공개 사전/계정 동기화/서버 백업은 **아직 구현하지 않았다**. ‘Private’ 표시는 로컬 상태 설명이지 접근 권한을 제공하는 서버 기능이 아니다.
- Safari의 웹사이트 데이터 삭제, 시크릿 모드 사용, 브라우저 변경 등으로 기록이 사라질 수 있다. 중요한 기록은 이 버전에만 보관하지 않는 것을 권장한다.

## 8. 수용 기준
- [ ] iPhone Safari에서 기본 감정 버튼을 탭하면 구슬 색이 바뀐다.
- [ ] 1/2/3/4개 선택 결과가 각각 단색/양방향/삼각형/사각형 그라데이션이다.
- [ ] 선택은 최대 4개까지이며 기록용 비중 입력은 없다.
- [ ] 혼합 화면에서 탭·롱프레스가 방울 수에 반영된다.
- [ ] 섞기 전 비율 미공개, 섞기 후 비율 공개.
- [ ] 이름 없이 만든 감정도 Private 사전에서 재사용된다.
- [ ] 저장하면 구슬이 달력의 오늘 날짜 칸으로 들어간다.
- [ ] 새로고침 후에도 같은 브라우저에서 기록이 유지된다.
- [ ] Reduce Motion 설정에서 불필요한 이동 애니메이션이 생략된다.

## 9. 이번 범위에서 제외
- 유체 시뮬레이션/Metal급 셰이더, 알림 및 감정의 유통기한.
- 월간·연간 핀치 줌, 감정 랭킹, 누적 감정 지도.
- 심리학 이론에 근거한 기본 감정과 색 체계의 최종 확정.
- Public 사전 탐색, 유의어 추천, 정의 검색.
- 계정, 클라우드 동기화, 수출/백업.
