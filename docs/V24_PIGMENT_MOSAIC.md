# V24 — 사진 속 색채 모자이크와의 거리 좁히기

사용자가 제공한 참고 사진은 사진/인쇄물에 가까운 1000여 개의 작은 색면이 거의 빈틈없이 쌓인 장면. 현재 연간 달력은 월 12열의 질서정연한 UI로, 색상이 단 8개로 반복되고 각 구슬의 숫자·틈새가 두드러져 자연스러운 색면보다는 데이터 그리드처럼 보였다.

## 시각 변화
- **색:** 고채도 8색 반복 대신 데모 기록에 8개 감정 그룹별 6가지 톤, 총 48가지 스와치를 할당. 사진에서 관찰되는 살구·테라코타·크림·물빠진 코랄·파우더 블루·세이지 계열.
- **분포:** 데모에서 밝은 색과 따뜻한 색이 조금 더 자주 나와 다양한 색이 조화롭게 섞이도록 가중치 조절. 결과는 시드로 고정되어 비교하기 쉬움.
- **밀도:** 연간 12개 월 그룹 구조는 유지하면서 가로 3→1px, 세로 4→1px 간격으로 좁힘. 구슬이 거의 맞닿아 거대한 연속 색면으로 보임.
- **재질:** 얇은 무광 인쇄 테두리(~0.8px). 글로우·강한 외곽 그림자·입체 하이라이트 없음.
- **날짜:** 연간 일자 숫자는 완전히 삭제하지 않고 대비만 낮춰 색을 우선하도록 조정. 터치 영역, 접근 가능한 날짜, 상세 보기 그대로.
- **그라데이션:** 샘플 30%는 CSS 2·3색 선형 그라데이션으로 빠르게 표현. 고비용의 224px 유니크 Canvas 그라데이션 대량 생성 피함. 기존 진짜 기록과 오늘의 감정 렌더러에는 적용하지 않음.
