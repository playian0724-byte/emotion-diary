# 결. — V4 미니멀 디자인 시스템

## 디자인 방향
**색은 구슬에만. 나머지는 조용하게.**

코펜하겐의 현대적인 편집·제품 디자인을 참조하는 시각적 원칙으로, 다른 앱 UI처럼 과도한 그라데이션·섀도·감성 카피·장식을 쌓지 않는다.

### 1. 역할 분리
- **감정 구슬**: 선명한 색, 입체적인 유리 질감, 부드러운 표면광과 가장자리 반사
- **텍스트/레이아웃**: 중립적인 흑백에 가까운 색, 충분한 여백, 얇은 구분선, 차분한 타이포
- **버튼/카드**: 단색, 얇은 테두리, 작은 모서리 반경
- **수면**: 구슬보다 한 발 물러난 중성적인 배경. 혼합 애니메이션의 캔버스
- **저장 애니메이션**: 꾸밈보다 구슬이 날짜로 이동한다는 의미에 집중

### 2. 색상 규칙
기본 팔레트는 생생하게 유지하되 네온처럼 발광시키지 않는다.

| 기쁨 | 평온 | 슬픔 | 불안 | 분노 | 놀람 | 혐오 | 기대 |
|---|---|---|---|---|---|---|---|
| `#FFD02F` | `#20C4AD` | `#3389EF` | `#9557E6` | `#F15C63` | `#FB9B2D` | `#62C44B` | `#F36E9D` |

기본 팔레트는 **디자인 실험용**으로, 과학적으로 확정된 감정-색상 연결을 주장하지 않는다.

### 3. 구슬 재질
외형은 '강한 광택의 투명 젤/유리'에 가깝다.

- 좌상단의 큰 분산 하이라이트 1개
- 테두리를 따라 얇은 내부 반사
- 우하단의 약한 음영으로 깊이 형성
- 구슬 저장 비행 시 구슬 자체가 회전하므로 반사광도 함께 회전
- 너무 큰 흰색 조명으로 감정색을 지우지 않음
- 빈 구슬에는 광택을 사용하지 않음
- 모바일 CSS pseudo-element 기반이며 Apple의 시스템 Liquid Glass API 구현은 아님

### 4. 문구 규칙
감정 판단, 과장, 칭찬, 시적인 장문, 반복적인 설명은 피한다.

- '오늘은 어떤 마음이었나요?' → **오늘의 감정**
- '표현하기 어렵다면, 새 감정 만들기' → **새 감정 만들기**
- '무슨 일이 있었나요? 적지 않아도 괜찮아요.' → **기억하고 싶은 것**
- '오늘의 구슬을 남겼어요.' → **저장됨**
- '감정들이 하나의 색으로 모이는 중…' → **섞는 중**
- 완료 결과 안내 → **완성**
- 상세 설명은 실제 필요할 때만 제공하고 나머지는 감춤

### 5. 코너/음영
- UI 카드 반경은 약 9–13px로 통일
- 음영은 원칙적으로 없고, 구슬에만 계층감 부여
- 전체 배경은 오프화이트 `#fbfcf9`, 대비는 절제
- 작은 본문/메모의 읽기 쉬운 대비 유지

### 6. 사용자 데이터
- 기존 `gyeol-v2` localStorage 키 유지: 기록·메모·개인 감정 정의 삭제 없이 적용
- 새 팔레트는 기본 감정 색 표시를 변경함
- 사용자가 이전에 만든 감정의 고유 색상은 유지됨
- 기록은 여전히 로컬 저장이며 서버 동기화/백업 미구현

### 7. QA 체크리스트
- [ ] iPhone Safari에서 모든 감정 버튼이 보이고 터치 가능
- [ ] 단일 색 및 2~4색 구슬의 하이라이트가 색을 과하게 덮지 않음
- [ ] 저장 시 회전·이동하는 구슬의 광택이 깨지지 않음
- [ ] 혼합 후 완성 구슬에도 동일한 재질감이 적용
- [ ] 빈 날짜 구슬은 색과 광택이 없음
- [ ] 메모 필드, 혼합 버튼, 사전의 긴 이름이 작은 화면에서 잘리지 않음
- [ ] 새로고침 후 기존 로컬 기록이 유지
- [ ] V4의 짧은 문구가 이해하기 어려운 동작을 만들지 않음

## 추후 검토
기본 색과 감정의 대응 관계는 심리학 검토 및 사용성 실험 후 확정한다. 지나친 채도는 소형 아카이브에서 피로도를 높일 수 있으므로 일간 1개/월간 수십 개/연간 수백 개 밀도에서 각각 평가한다.
