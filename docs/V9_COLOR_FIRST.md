# 결. V9 — Color First

**결정:** 감정을 기록하는 행위와 색 자체를 주인공으로 되돌린다. 발광, Shimmer, 광원, 후광, 유리광택은 당분간 보류한다.

## 디자인
- 1개 감정: 해당 감정의 **원래 HEX 색상을 그대로** 하나의 동그란 면으로 렌더링.
- 2개 감정: 서로 마주 보는 두 가지 선명한 색, 그 사이만 부드럽게 이어짐.
- 3개 감정: 삼각형 꼭짓점에서 출발하는 세 색.
- 4개 감정: 사각형 꼭짓점에서 출발하는 네 색.
- 3~4색은 약간 강화된 꼭짓점 비중으로 각 색이 보이도록 하고, 선과 색 경계는 부드럽게 유지.
- 모든 구슬에서 별도 흰 테두리, 그림자, 반사, Shimmer, 외부 빛을 사용하지 않음. 원형 윤곽에만 안티앨리어싱 사용.
- 달력 작은 구슬, 감정 만들기 결과 단색 구슬, 저장 중 이동하는 구슬도 같은 시각 언어 사용.
- 기존 오프화이트·짧은 한국어 UI 카피와 모바일 레이아웃 유지.

## 구현
- `app.js`의 `orbStyleForColors()`에 색상만 있는 224px Canvas 텍스처를 사용하고 `v9-flat` 캐시 키를 적용.
- V5~V7 발광 CSS는 기본 스타일에서 정리하고, V9 규칙으로 불필요한 pseudo-element, 그림자, 애니메이션을 끔.
- 기본 모드는 원색 V9. V8.2 WebGL2 광원 연구용 실험은 `?renderer=webgl`에서만 실행하도록 보존.
- 기존 기록, 메모, 나의 감정 사전, 감정 방울 혼합, 저장 애니메이션, localStorage 키 `gyeol-v2`는 그대로 유지.
