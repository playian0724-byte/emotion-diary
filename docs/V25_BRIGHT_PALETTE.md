# 결. V25 — 맑고 따뜻한 반파스텔 컬러

이전 V24 사진 레퍼런스 구현이 칙칙해 보인다는 피드백을 반영했다.

## V24 → V25 변화
- 8개 감정군 × 6개 색조 = 총 48개 데모 스와치를 **좀 더 밝고 선명한 색**으로 교체.
- 의도: 따뜻한 크림·버터 옐로우·코랄·오렌지에 맑은 하늘색·민트·라일락이 살아 있는 촘촘한 색면.
- 매 구슬의 색조 그룹을 밝은 35%, 중간 45%, 선명한 포인트 20%로 가중 선택. 밝기와 채도의 대비가 있어 유화 같은 색 조각이 지나치게 평평해 보이지 않게 함.
- RGB HSV 평균 채도(48종 단순 평균): V24 약 0.327 → V25 약 0.403, 약 23% 상승. 이는 색감 변화의 보조 지표이며 시각적 품질 보증은 아님.
- 그라데이션도 서로 멀리 떨어진 보색 조합을 줄여 중간색이 갈색/회색으로 탁해지는 현상을 완화. 2색의 양 끝 8%/92%, 3색은 6%/50%/96%로 조정.
- 색을 누르던 구슬 테두리 불투명도를 0.24 → 0.12로 완화. 빈 원도 배경과 어울리는 밝은 화이트 톤.
- V24의 연감 12열 지그재그, 아주 촘촘한 간격, 글자 가독성 제한, V22~23 핀치 모션은 유지.

## 테스트 범위
- `?demo=1`에서만 새 색을 사용. **실제 오늘/사전 감정 기본색, 개인 기록, localStorage `gyeol-v2`에는 변경 없음**.
- 앱 화면의 `실제 기록 보기`로 빠져나오면 정상 개인 아카이브가 나타남.
- 새로고침해도 의사난수 생성 시드가 같아 같은 날짜에 같은 색이 나타남.
