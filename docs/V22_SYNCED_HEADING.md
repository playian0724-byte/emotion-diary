# 결. V22 — 동일한 연도 헤더, 핀치 중 제목 페이드

## 요청
- 3개월·6개월 상단에 표시되던 `03–06`, `07–12` 등의 범위 텍스트 제거. 1년 뷰처럼 **연도 숫자만** 표시.
- 연월 텍스트가 손을 놓은 뒤 따로 페이드하지 말고 **핀치 중 구슬이 움직이는 진행률과 동시에 페이드**.

## 변경
1. `periodHeaderMarkup(date,span)`: span=1일 때만 가볍게 연도+볼드 월, span=3·6·12일 때는 연도 숫자 하나만 출력.
2. 3·6·12개월은 동일한 `.poster-year` 큰 연도 타이포그래피를 공유. 각 월 블록의 `01`~`12` 라벨은 유지.
3. 다음 줌 레이아웃을 준비할 때 **다음 제목도 준비**하여 같은 위치에 겹침. 처음에는 투명도 0.
4. `drawStage(p)`: 날짜 구슬 `translate3d/scale`에 사용하는 바로 그 `p`로 기존 제목은 `1-p`, 다음 제목은 `p`로 조절. 따라서 손가락이 움직일 때 제목도 동시에 전환.
5. 손을 놓을 때 기존·새 제목이 가진 현재 opacity를 보존하고, 남은 구간만 최대 약 205ms에 걸쳐 끝냄. 방금 진행된 페이드를 0부터 재시작하지 않음.
6. 작은 핀치를 취소하거나 방향을 바꾸면 기존 제목 opacity를 복원하고 미리보기 제목 제거. 연속 확대·축소에도 제목 잔상을 정리.
7. 기존 날짜 구슬 개별 이동, 76개 상한, 기록 숨김/복원, `gyeol-v2` 데이터, 감정 혼합 기능 유지.
