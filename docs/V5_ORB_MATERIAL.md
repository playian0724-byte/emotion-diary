# 결. V5 — 자연광 구슬 재질 명세

## 목표
사용자가 제공한 매끈하게 연마된 파란 구체 사진의 조명 원칙을 참고한다. V4에서 과도했던 유리 테두리와 겹친 광택 효과를 없애고, 하나의 광원 아래 실제 물체처럼 보이는 감정 구슬을 만든다. UI의 미니멀한 구성은 유지한다.

## 시각 원칙
- 테두리의 별도 색상·윤곽선을 그리지 않는다.
- 가장자리는 표면 법선과 광량에 따라 같은 색 계열로 자연스럽게 어두워진다.
- 좌상단의 하나의 부드러운 하이라이트와 옅은 주변광을 사용한다.
- 내부에 겹친 CSS 그림자와 가짜 흰색 림 라이트를 제거한다.
- 단색, 2~4색 그라데이션, 혼합 결과, 달력과 저장 중 구슬에 같은 광원과 재질을 적용한다.
- 앱의 나머지 인터페이스는 코펜하겐 디자인처럼 담백한 타이포와 오프화이트 여백, 간결한 문구를 유지한다.

## 기술 구성
- app.js의 orbStyleForColors()에서 Canvas ImageData를 이용해 표면을 생성한다.
- 구 내부의 x/y 좌표와 z 높이를 계산해 확산광을 적용한다.
- 주광원에 대응하는 소프트한 반사광만 계산해 픽셀의 RGB에 함께 합성한다.
- 외곽은 안티앨리어싱만 처리하며 테두리용 stroke나 hue-shift를 만들지 않는다.
- 구슬의 표면을 메모리 캐싱해 달력과 오늘 기록에서 같은 결과를 재사용한다.
- CSS의 과장된 glass 하이라이트, 하얀 림, 여러 내부 음영 레이어를 비활성화한다.
- 혼합 완료 구슬에도 동일한 렌더러를 적용한다.

## 데이터와 사용 경험
- 기존 기록용 1개 단색, 2개 양방향, 3개 삼각형, 4개 사각형 색 배치 유지.
- 감정 혼합은 별개로 상대 비율에 따라 새 단색 감정을 만드는 과정이다.
- 스포이드 탭/롱프레스, 회전 혼합 애니메이션, 구슬 저장 후 달력으로 이동하는 과정 유지.
- 기본 감정 팔레트는 V4와 동일하여 기존의 사용자 생성 감정 색은 변하지 않는다.
- localStorage의 gyeol-v2 데이터를 그대로 사용하며 기존 기록을 삭제하거나 변환하지 않는다.

## iPhone Safari 확인 사항
- [ ] 단색 파란 구슬의 가장자리에 다른 색의 얇은 선이 없는지
- [ ] 표면 하이라이트가 스티커처럼 별개로 보이지 않는지
- [ ] 3~4색 구슬의 색 배치가 의도대로 나타나는지
- [ ] 혼합 결과 구슬에도 동일한 재질이 적용되는지
- [ ] 저장 시 작은 구슬이 달력에 자연스럽게 들어가는지
- [ ] 이전 기록과 내 감정 데이터가 유지되는지
- [ ] 화면 전환 및 감정 선택 성능이 유지되는지

**한계:** 이 구현은 광원과 곡면을 근사한 Canvas 기반 2D 렌더러이다. 사진을 정확히 복제한 3D 실사 렌더는 아니며, 실제 Safari 화면은 기기에서 검증해야 한다.
