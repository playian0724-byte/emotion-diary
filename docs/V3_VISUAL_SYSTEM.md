# 결. — V3 색채 및 감정 혼합 애니메이션 설계

작성일: 2026-10-10  
상태: 시제품 구현 완료 · 실제 iPhone Safari 사용자 검증 대기

## 이번 수정의 출발점
V2에서는 ‘섞기’ 버튼을 누르면 수면이 흐려지고 사라진 뒤 최종 구슬이 별개로 등장했다. 사용자는 물감들이 **서로 섞인 결과가 바로 그 구슬이 되는 과정**을 원한다. 또한 기존 기본 감정 팔레트가 지나치게 비슷한 파스텔 톤이어서 구슬이 단조롭다는 피드백이 있었다.

## V3 변경 사항

### 1. 기본 감정 팔레트
| 기본 감정 | 색상 | 역할 |
|---|---|---|
| 기쁨 | `#F9C83C` | 황색 |
| 평온 | `#36BAA3` | 선명한 청록 |
| 슬픔 | `#448CDE` | 청색 |
| 불안 | `#9865D9` | 자주색 |
| 분노 | `#E95D62` | 적색 |
| 놀람 | `#F59D36` | 주황 |
| 혐오 | `#70BA59` | 녹색 |
| 기대 | `#EF76A0` | 분홍 |

팔레트는 **다채로운 디자인을 검토하기 위한 시안**이지 특정 감정과 색채의 관계가 심리학적으로 확립되었다는 뜻이 아니다.

샘플 개인 감정도 이전의 잿빛 팔레트에서 구분 가능한 색으로 수정했다. 사용자가 이미 직접 만든 감정의 저장 색상은 바꾸지 않는다.

### 2. 수면에서 구슬로 이어지는 하나의 애니메이션
혼합 영역은 하나의 공통 무대 `mix-stage`를 사용한다.

- **방울 입력:** 탭당 한 방울, 롱프레스 연속 추가. 기존 5~10초의 기록 철학과는 별개의 선택 기능이다.
- **번짐:** 캔버스에서 개별 색의 반투명 원형 잉크가 물 위로 확장되고 옅은 동심원 물결이 나온다.
- **혼합 시작:** 약 1.7초간 개별 색 덩어리가 중심을 향해 회전·수축한다.
- **색상 전이:** 각 잉크 덩어리의 색이 시간 경과에 따라 최종 혼합색으로 가까워진다.
- **구슬 응집:** 같은 중앙 위치에서 단색 구슬이 서서히 또렷해지고 수면 레이어는 점차 사라진다.
- **완료:** 혼합이 끝난 다음에 감정별 정확한 비율, 이름 및 정의 입력 영역이 나타난다.
- **다시 만들기:** 애니메이션과 결과 상태를 초기화하고 빈 수면으로 돌아간다.

**정확한 유체 시뮬레이션은 아니다.** Canvas의 라디얼 그라데이션과 위치 보간, 색상 보간, DOM 구슬 페이드·스케일을 결합한 물감처럼 보이는 연출이다. 모바일 저성능에서도 실제 유체 계산보다 가볍게 실행되도록 만들었다.

### 3. 색상 혼합 알고리즘
V2에서는 OKLab 공간에서 a/b 축을 단순 평균했기 때문에 반대 색상들이 자주 무채색화됐다.

V3는 OKLab의 **명도는 가중 평균**, **색상각은 원형 평균**, **채도는 가중 평균의 약 88%**를 목표로 보존하는 창작용 색상 보간을 사용한다. 마지막에 sRGB 표시 범위를 벗어나면 채도를 이분 탐색으로 줄인다.

- 같은 기본 감정과 같은 상대 비율은 항상 같은 결과 색.
- 2:1과 20:10은 같은 색.
- 감정별 정확한 비율은 ‘섞기’ 완료 후에만 공개.
- ‘오늘 기록’의 다색 구슬은 **단색 혼합과 무관**하게 여전히 각 감정 색을 보존.
- 3개/4개 기록 구슬에서는 삼각형·사각형의 꼭짓점 배치를 유지하되 내부 그라데이션 채도를 가볍게 보정.

이 방식은 실제 물감의 광학적 혼합을 재현하지 않고 **다채로운 감정 표현을 우선하는 디자인 모델**이다.

### 4. 데이터 및 호환성
- 로컬 저장 키 `gyeol-v2` 유지: 기존 메모·날짜·사용자 제작 감정·정의 손실 없이 읽음.
- 기본 감정의 색상은 ID에 연결되어 있으므로 **이전에 기본 감정으로 기록한 구슬의 표시색도 새 팔레트로 변경됨**. 날짜, 감정명, 메모는 유지.
- 이전에 직접 생성한 혼합 감정의 색은 저장된 고유 HEX 값을 유지하며 새 계산법을 소급 적용하지 않는다.
- UI 데이터는 여전히 브라우저 `localStorage`에만 존재. 계정 동기화와 백업 없음.

## 실제 iPhone Safari 테스트 항목
- [ ] ‘오늘’에서 기쁨/슬픔/평온 등 새로운 팔레트가 뚜렷하게 보이는지
- [ ] 1~4개의 선택 감정 구슬이 자연스럽게 보이는지
- [ ] 2~5방울을 넣고 섞으면 여러 색이 서로 접근하고 색이 변하면서 한 구슬이 되는지
- [ ] 혼합 완료 후에만 비율과 이름/정의 입력이 표시되는지
- [ ] 터치 입력과 길게 누르기가 버벅거리지 않는지
- [ ] 혼합 완료 → 사전 저장 → 오늘 감정 선택 → 구슬 저장 → 달력 이동이 모두 되는지
- [ ] ‘다시 만들기’가 누적 방울/혼합 상태를 올바르게 초기화하는지
- [ ] 화면이 좁을 때 완성된 구슬과 텍스트가 잘리지 않는지
- [ ] iOS Reduce Motion 설정을 켠 사용자에게 불필요한 모션을 축소할 수 있는지 (혼합 시각 효과는 후속 개선 대상)

## 후속 디자인 검증
1. 기본 감정색을 고정하기 전에 8색이 각기 충분히 구별되는지, 감정 의미와 일치한다고 느껴지는지 사용자 평가 필요.
2. 애니메이션 시간 1.7초를 1.2~1.5초로 줄일 필요가 있는지 확인.
3. 수면의 잉크 가장자리에 노이즈 기반 미세한 질감을 추가할지 검토.
4. 감정 사전 Public 공유, 알림/유통기한, 월·연간 확대, 내 감정 지도는 여전히 별도 개발 범위.
