# 결. V32 — 기록 유통기한과 수정

## 목적
감정을 기록할 때의 순간을 보존하고 싶다는 요구를 충족하기 위해, **설정에서 기록 수정 유통기한**을 선택할 수 있도록 구현.

## 설정
새로운 네 번째 탭 **설정** → **기록 유통기한**:
- **제한 없음** (기본값)
- **1시간**
- **24시간**
- **3일**
- **7일**
- **30일**

최초 저장 시각 `createdAt`부터 경과 시간을 계산. 24시간 설정이면 최초 저장한 정확한 시각부터 24시간이 지나는 순간 해당 일기는 읽기 전용으로 전환. **감정, 메모만 수정 금지**, 기록 자체와 날짜 구슬은 보존. 수정 성공 시 `editedAt`을 저장하되 `createdAt`은 변경하지 않으므로 수정으로 유통기한이 연장되지 않음.

## 사용법
기록 탭에서 해당 날짜 구슬 클릭 → 저장된 기록과 수정 가능 기한 확인 → **감정과 메모 수정** 버튼. 감정은 최대 4개 선택 가능, 메모 수정 가능. 기한이 만료된 기록은 수정 버튼 대신 읽기 전용 문구 표시. 저장 직전에 다시 한 번 만료 여부 검사. 기존 오늘 화면의 **오늘의 구슬 저장**에서도 만료 체크하므로 우회 불가.

## 기존 기록과 설정 변경
- 기존 데이터 저장 키 `gyeol-v2` 그대로. 저장 구조에 `settings.editExpiryHours`만 추가.
- V32 이전 일부 기록은 `createdAt`이 없을 수 있음. 정확한 최초 저장 시각을 알 수 없어 **해당 기록 날짜의 현지 23:59:59.999**를 기준점으로 대체. 임의로 새 저장 시각을 부여하지 않음.
- 설정 변경은 **이미 저장된 기록에도 소급 적용**. 이 설정은 장치 내 개인 기록 규칙이며 서버나 타인으로부터 기록을 보호하는 보안 잠금이 아님. 설정을 다시 **제한 없음**으로 바꾸면 기존 기록도 수정 가능.
- 데모 `?demo=1`는 실제 데이터를 건드리지 않으며 기록 수정과 설정 변경이 비활성화됨.
