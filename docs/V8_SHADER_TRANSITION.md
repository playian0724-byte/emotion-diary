# 결. — V8 셰이더 전환 설계안

**상태:** 설계를 토대로 V8 WebGL2 실험을 별도 비교 화면과 옵트인 모드로 구현. 기존 V7은 기본값이며 실기기 검증 필요. [구현/QA 문서](./V8_EXPERIMENT.md).  
**목표:** 겉의 흰 테두리를 없애고, 여러 감정의 색 분포를 따라 달라지는 후광을 만든다. 내부 빛/Shimmer/외부 후광을 하나의 시간·공간 모델에서 동시에 움직인다. 구슬 외 UI는 계속 미니멀하게 유지한다.

## 1. 원인 분석: V7에서 문제가 생기는 지점

확인한 기존 구조:
- `app.js`의 `orbStyleForColors()`는 Canvas ImageData로 정적 색유리 구슬 이미지를 생성한다.
- `paintOrb()`는 각 감정색을 `emotionGlow(colors, ...)`로 **하나의 평균 후광색**으로 축약하고 `--orb-halo`에 할당한다. 2~4색 구슬도 후광 전체가 같은 색인 이유다.
- `styles.css`의 `.orb::before`·`.orb::after`는 별도의 흰색 radial-gradient Shimmer 레이어다. 구슬 가장자리에서 흰색 링/테두리처럼 보일 수 있다.
- CSS keyframes는 전체 box-shadow 및 두 흰색 레이어를 각각 변환한다. 시간 주기는 같지만 실제 광원의 위치·색 분포를 픽셀별로 공유하는 단일 조명 계산은 아니다.

**결론:** 단지 glow의 세기를 높이거나 CSS 레이어를 계속 추가해도 핵심 문제가 남는다.

## 2. 무엇을 버리고, 무엇을 보존할까?

| 구분 | V8 방침 |
|---|---|
| 정적 Canvas 구슬 PNG 렌더링 | **큰 구슬에서는 폐기**, 달력·fallback에서는 정적 경량 렌더링으로 재사용/교체 |
| 구슬 위 흰색 `::before`, `::after` | **구슬 셰이더 경로에서 제거** |
| 전체 한 가지 색 `box-shadow` | **제거**하고 GPU에서 각 픽셀의 halo 색 계산 |
| V7 CSS 광원 키프레임 | GPU의 단일 `time` 및 `lightPosition`으로 통합 |
| 감정 데이터·로컬 저장 | **그대로 유지**: `gyeol-v2`, record/custom 스키마 및 메모 |
| 일반 기록과 새 감정 만들기 | **분리 유지**: 기록은 1~4개 색의 공존, 새 감정은 비율을 섞은 단색 |
| 현재 미니멀 UI | 변경하지 않음 |
| 달력으로 구슬이 날아가는 저장 UX | 유지. 이동 중에는 애니메이션 1프레임으로 고정 |

## 3. 기술 선택 및 앱 구조

**우선 구현:** iOS Safari에서 지원 가능한 **WebGL2 (GLSL ES 3.00)**. WebGPU 단독 사용이나 새 외부 셰이더 라이브러리는 필수가 아니다.

권장 파일 분리:
- `shaders/orb.vert.glsl`: 화면 사각형을 출력하는 단순 정점 셰이더.
- `shaders/orb.frag.glsl`: 구슬 내부 색·발광·Shimmer·외부 후광의 픽셀 계산.
- `orb-renderer.js`: WebGL2 초기화, uniform 관리, resize, frame scheduling, context loss 복구, static capture.
- `app.js`: 기존 감정 선택/저장/사전/기록 데이터 로직 유지. `paintOrb()` 등 화면 연결점만 renderer 인터페이스로 교체.
- `styles.css`: 위치·크기·여백만. 구슬의 표면광과 halo에는 흰색 pseudo-element나 CSS shadow를 사용하지 않음.
- `index.html`: 구슬 자리마다 셰이더용 캔버스 호스트. 작은 달력 구슬은 정적 이미지/2D canvas.

렌더링 계약 예:
```js
const renderer = createOrbRenderer(container, {
  colors: ["#FFD02F", "#3389EF"],
  mode: "daily",       // daily = 감정 공존 / mixed = 단색
  animate: true,
  quality: "auto"
});
renderer.setColors(colors);
renderer.start();
renderer.pause();
renderer.snapshot();  // 저장 애니메이션용 정적 1프레임
renderer.dispose();
```

**렌더 대상:** 한 번에 **큰 구슬 하나**만 실시간 애니메이션. 오늘 화면과 혼합 결과 화면은 활성화된 쪽만 움직이고 비활성화된 쪽은 정지. 월간 구슬 수십 개를 WebGL context 수십 개로 렌더링하면 안 된다.

## 4. 셰이더 좌표계와 다색 분포

캔버스는 구슬 지름의 약 **1.5~1.7배**가 되도록 구성해 바깥 halo까지 같은 텍스처 공간에서 표현한다. 정규화 좌표 `p=(x,y)`, 구슬 반지름 `r=1`.

- `length(p) < 1`: 얇은 색유리 표면, 내부 조명, 확산, 부드러운 Shimmer.
- `length(p) > 1`: 반투명 외부 빛. 바깥 색은 해당 위치 방향의 감정색을 샘플링한 값.
- 구슬 윤곽에서 단색 흰색 선을 생성하는 별도 명암/투명도 피크를 만들지 않는다. `smoothstep` 기반 1~2px의 안티앨리어싱만 허용.

**기존 기하 규칙 유지:**
- 1색: 단색.
- 2색: 마주 보는 두 방향에서 각 색이 넓은 영역을 차지함. 중앙 전이만 살짝 좁게.
- 3색: 원의 외접 삼각형 **세 꼭짓점**에서 각각의 색이 퍼지는 공간 분포.
- 4색: 원의 외접 사각형 **네 꼭짓점**에서 각각의 색이 퍼지는 공간 분포.
- 3·4색에서는 기존 지수 기반 가중치를 약하게 적용해 코너별 색 존재감을 유지. 예: `normalized(pow(max(weight,0), 1.48))`.
- 그라데이션 자체는 어떤 감정의 양을 의미하지 않는다.

권장 공용 함수:
```glsl
vec3 pigmentAt(vec2 p);  // p에 위치한 감정색; 1~4개 입력
```

이 함수를 **구슬 안쪽에도, 바깥 halo에도 똑같이 사용**하는 게 핵심이다.

## 5. 내부 광원, Shimmer, colored halo

### A. 빛이 유리 안에 있는 느낌
표면에 흰색 원을 얹지 않는다. 내부에 있는 흐린 광원 중심 `L(t)`로부터 픽셀까지의 거리와 유리 두께를 반영해 빛 산란을 계산한다.

```glsl
vec2 L = vec2(0.13 * sin(t * 0.68), 0.11 * cos(t * 0.68));
float core = exp(-dot(p-L,p-L) / (2.0 * 0.19 * 0.19));
float scatter = exp(-dot(p-L,p-L) / (2.0 * 0.47 * 0.47));
```

`core`는 눈에 띄는 내부 불빛, `scatter`는 구체 전체로 옅게 번지는 빛. 중심의 빛은 완전 흰색보다는 **해당 감정색이 섞인 밝은 색**으로 설정해 매끈한 색유리 느낌을 유지한다. 코어가 지나치게 밝으면 사용자 레퍼런스가 아닌 네온/LED 장난감처럼 보일 수 있으므로 상한을 둔다.

### B. Shimmer는 같은 광원을 따라 이동
Shimmer의 큰 형상/미세한 투명 결은 `L(t)` 주변 위치의 보조항으로 만든다. 완전히 독립된 무작위 궤도 금지. 구슬 밖 테두리에서 반사가 상승하지 않도록 마스킹한다.

### C. 바깥 후광은 색 위치를 따라감
`p`가 구슬 밖이라면 `q = normalize(p)*0.94` 위치의 감정색 `pigmentAt(q)`를 샘플링해 후광 색으로 사용한다. 즉 왼쪽이 노란 구슬이면 **왼쪽 후광은 노랑**, 오른쪽이 파랑이면 **오른쪽 후광은 파랑**이다.

후광 강도 = 경계와의 거리로 줄어드는 부드러운 감쇠 × 내부 광원 방향과 맞닿는 영역의 가중치. 거리 감쇠와 움직임은 한 shader에서 같은 `L(t)`를 참조한다.

예시 의사코드:
```glsl
float distOut = max(length(p)-1.0, 0.0);
vec3 localHue = pigmentAt(normalize(p)*0.94);
float haloFalloff = exp(-pow(distOut / 0.28, 2.0));
float directional = 0.68 + 0.32 * dot(normalize(p), normalize(L + vec2(0.001)));
vec3 halo = localHue * haloFalloff * directional * uGlowStrength;
```

이건 계산 구조 예시이며 완성된 GLSL 코드가 아니다. 경계가 밝은 띠로 나타나지 않도록 `r=1`의 alpha/색 보간을 테스트한다. 투명도와 색 합성은 가능하면 선형 RGB 및 premultiplied alpha 원칙으로 처리한다.

### D. 모두 하나의 시간축
Shader의 `uTime`을 중심으로 내부 불빛 이동, Shimmer 강도, halo 방향을 계산한다. 서로 다른 CSS 애니메이션들의 위상 어긋남을 없앤다. 5~8초의 느린 주기를 기본 후보로 잡고 실제 기기에서 조절한다.

## 6. 큰 구슬과 달력 구슬을 별도 렌더링

| 대상 | 렌더 방식 | 모션 |
|---|---|---|
| 오늘 기록 큰 구슬 | WebGL2 shader | 천천히 이동하는 내부 광원 + 색깔별 동적 halo |
| 새 감정 혼합 결과 큰 구슬 | 동일 shader, 단색 입력 | 동일한 조명 모델. 물감 응집 애니메이션은 기존 Canvas 수면 활용 |
| 저장 중 날아가는 구슬 | shader의 프레임을 정적 이미지로 캡처 | 회전·축소·이동만 |
| 월간 달력 작은 구슬 | 정적 PNG/2D texture를 조합별 캐시 | 없음. 정적인 아주 약한 색상 후광은 허용 |
| WebGL2 실패 시 | Canvas 2D fallback | 기본 구슬/기록/저장 기능 유지 |

작은 구슬 여러 개 때문에 WebGL 컨텍스트를 늘리지 않는다. 캐시 키에 색상 조합, 렌더 버전, 필요시 quality를 포함한다.

## 7. 모바일 성능과 접근성

- 한 번에 1개 실시간 GPU 캔버스. 처음엔 30fps를 목표로 실제 Safari 성능 측정 후 조정.
- GPU 렌더 해상도는 CSS 표시 크기와 기기 DPR을 고려하되, 내부 픽셀 크기에 상한을 둔다.
- 페이지가 비활성화되거나 다른 탭으로 이동하면 `requestAnimationFrame` 중단.
- `prefers-reduced-motion`인 경우 정적인 광원/후광으로 대체.
- `webglcontextlost`, `webglcontextrestored` 처리 및 fallback 제공.
- 배터리 발열, 터치 반응, 스크롤 부드러움, Safari 장시간 안정성을 확인.
- WebGL2 지원 실패는 일반적인 앱 기능 실패로 이어져선 안 된다.

## 8. 구현 순서

1. **별도 테스트 화면에서 1색 구슬 WebGL2 POC 구현:** 내부 발광/후광/흰 테두리 제거부터 검증.
2. **2색 구슬 검증:** 노랑+파랑, 빨강+파랑에서 각 방향의 후광 색 분리 확인.
3. **3색/4색 꼭짓점 보간 연결:** 색 영역이 너무 뭉개지거나 너무 날카롭지 않은지 조정.
4. **공용 시간축에 Shimmer/halo 이동 연결:** 실제 사용자 레퍼런스와 움직임 비교.
5. **오늘/혼합 결과/달력 저장 연결:** 기존 비즈니스 로직은 유지, 시각 렌더링 층만 교체.
6. **정적 달력 렌더링·iOS 최적화·fallback 구현.**
7. **버전 비교 테스트:** V7과 V8을 같은 색 조합에서 나란히 비교. 기준 통과 후 기본 웹앱 화면으로 승격.

처음부터 V7 코드를 덮어쓰지 않고 feature flag (예: `?renderer=webgl` / `?renderer=legacy`)로 같은 사이트에서 A/B 비교한다.

## 9. V8 수용 기준

- [ ] 흰색/다른 색 테두리가 보이지 않는다.
- [ ] 2색 구슬에서 양쪽 후광이 각자의 색으로 나타난다.
- [ ] 3색/4색도 각 코너 주변 후광이 서로 다른 색이다.
- [ ] 내부 빛과 halo가 **같은 방향, 같은 타이밍**으로 천천히 움직인다.
- [ ] Shimmer는 눈에 보이되 표면 위에 붙인 흰 원처럼 보이지 않는다.
- [ ] 2~4색의 각 감정색 영역을 V6와 같은 수준 이상으로 유지한다.
- [ ] 달력 작은 구슬은 조용하게 정지한다.
- [ ] 구슬 저장 비행 및 기존 감정 기록/사전 동작은 손상되지 않는다.
- [ ] iPhone Safari에서 터치 지연/발열/크래시 없이 작동한다.
- [ ] WebGL이 지원되지 않아도 앱이 사용 가능하다.
- [ ] 기존 localStorage 기록을 그대로 읽는다.

## 10. 제품 방향

네가 선택한 시각적 기준: **인사이드 아웃의 얇은 색유리 속 불빛 같은 감정 구슬**. 표면의 광택보다 내부 광원의 실제 존재감을 강조한다. 코펜하겐풍 미니멀한 화면에서 구슬만 부드럽게 살아 움직여야 한다.

**주의:** 셰이더만 바꾼다고 자동으로 사진처럼 사실적이 되지 않는다. 광원, 유리 두께, 색 산란, halo의 범위와 강도를 실제 화면에서 반복 조절해야 한다.
