# 결. V33 — 유한한 감정 기록 유통기한

## 변경 사항
V32에서 제공하던 **제한 없음**과 **30일** 선택지를 삭제.

설정 화면에 남는 선택지는:
- 1시간
- **24시간 (기본값)**
- 3일
- 7일

유통기한은 최초 저장 시각부터 계산하며, 시간이 지나면 해당 기록의 감정과 메모를 수정할 수 없음. 기록은 지우지 않고 아카이브에서 언제든 열람할 수 있음. 기존 감정 구슬과 모든 디자인·핀치 모션은 보존.

## 이전 버전 데이터
기존 저장 데이터의 유통기한이 **0시간('제한 없음')**, **720시간('30일')**, 또는 누락/잘못된 값이면 **24시간**으로 자동 정규화하여 사용. 저장된 기록과 메모를 삭제하거나 다시 쓰지 않으며, 설정은 다음 변경/저장 시 `gyeol-v2` 안에 새 값으로 저장됨.

기한 변경은 기존 기록에도 소급 적용됨. 예를 들어 1시간에서 7일로 바꾸면 해당 기록의 최초 저장 이후 7일이 지나지 않은 경우만 수정 가능. **7일을 넘긴 기록은 어떤 설정에서도 수정할 수 없음.**

V32 이전 시점에 저장되어 `createdAt`이 없는 기록은 이전 버전과 똑같이 **기록일 23:59:59.999 (로컬 시간)** 기준으로 계산. 수정 시 최초 저장 시각은 그대로 유지.
