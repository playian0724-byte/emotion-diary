# 결. V29 — 가운데는 단색, 바깥 링만 분할

V28 피드백: 4감정일 때 내부원까지 두 색으로 나누면 중심이 어수선해 보임. 4개 감정이어도 한 가지 중심색을 유지하고 나머지 색은 외부 링만 분할.

## 최종 규칙

| 감정 수 | 가운데 원 | 바깥 |
|---|---|---|
| 1 | 첫 감정 한 색으로 전체 원 | 링 없음 |
| 2 | 첫 번째 감정색 (단색) | 두 번째 감정색 (단색) |
| 3 | 첫 번째 감정색 (단색) | 두 번째·세 번째 감정색을 각각 180° 반원 |
| 4 | 첫 번째 감정색 (단색) | 두 번째·세 번째·네 번째 감정색을 각각 120° 부채꼴 |

바깥 링 두께를 조금 더 키우기 위해 **내부원 지름을 구슬 지름의 69% → 62%**로 축소. 외곽 링 두께는 구슬 지름의 15.5%에서 19%로 증가(상대 약 22.6% 증가).

## 구현
- 실제 렌더 함수 `orbDiscColors`가 순서를 유지하며 1–4감정 형태를 계산.
- 4감정 바깥 링은 하드 스톱 CSS `conic-gradient`의 세 개 120도 조각으로 구현. 색상 혼합이 아니라 정수 각도의 명확한 경계이며 가운데 색상은 `c[0]` 하나.
- 3감정의 바깥 반반 링과 2감정의 동심원은 유지.
- V28의 재사용 가능한 DOM 내부원 `.orb-center`를 쓰고 `width:62%; height:62%`로 조정.
- 날짜 숫자색은 모든 경우 **첫 번째 감정색**에 매핑된 고정 `ink`를 사용(중심이 언제나 단색이므로 4감정 혼합 대비 계산 불필요).
- 오늘 미리보기, 날짜 구슬, 저장 이동 애니메이션, 1/3/6/12개월 핀치 미리보기, demo 모드에서 같은 기능을 공유.
- `gyeol-v2` 구조와 개인 기록 내용은 변경하지 않음.
