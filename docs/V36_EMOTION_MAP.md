# 결. V36 — 나의 감정 지도 (Emotion Atlas)

## 위치
**사전 탭의 상단**에 개인 감정 지도를 배치하고, 그 아래에 기존 **나의 감정 사전/새 감정 만들기**를 그대로 둔다. 기록 탭은 "언제 어떤 감정이 있었는지", 사전 탭은 "어떤 감정이 나를 이루고 서로 연결되는지"를 보여준다.

## 데이터와 시각 규칙
- 원 하나가 감정 하나. 기본 감정 8종과 기록에 실제로 사용된 개인 감정(사전에서 만든 감정 등)을 포함.
- 원 크기는 해당 감정이 등장한 **기록된 날짜 수**에 비례하는 비선형 크기. 같은 날 같은 감정이 중복되어도 1회만 센다.
- 두 감정 사이에는 같은 날짜에 **둘 모두** 등장한 횟수만큼 연결선을 그린다. 자주 함께 나온 쌍일수록 선이 **굵고 진해짐**. 선은 평평한 저채도 녹회색이며 장식적인 광택이나 그림자를 넣지 않는다.
- 강하게 연결된 감정은 부드러운 스프링 인력으로 가까워지게 배치. 서로 겹치지 않도록 결정론적 거리 기반 배치/충돌 완화 수행. 방문할 때마다 색상 원이 무작위로 이동하지 않는다.
- 감정 원을 탭하거나 포커스 후 Enter/Space를 누르면 관련 선과 노드를 강조하고 실제 빈도 및 가장 자주 같이 등장한 감정 4개를 텍스트로 설명. 다시 누르면 전체 지도.
- **전체** / **최근 30일** 두 가지 기간 전환 가능, 데이터는 로컬 기록 기준으로 실시간 계산.
- 감정 수가 많으면 상위 16종만 지도에 배치하며 실제 전체 감정 수는 안내 텍스트로 표시; 연결쌍이 매우 많으면 가장 강한 50개만 표시. 이는 좁은 모바일 너비에서 읽기 위한 시각적 제한이다.
- 기록 수가 0이면 빈 화면 안내와 **샘플 감정 지도 보기** 링크 제공. \`?demo=1&view=map\`는 기존 샘플 기록을 메모리에만 생성하며 사용자 실제 기록을 덮어쓰거나 저장하지 않는다.
- 감정 원의 색은 기존 팔레트에서 변경하지 않는다. 진단이나 감정의 긍정/부정 순위를 매기지 않는다.

## 스토리지 및 성능
- 기존 \`gyeol-v2\` 그대로. 새 감정 지도는 **파생 통계**이므로 저장 스키마를 추가하지 않는다.
- 반복 애니메이션이나 백그라운드 물리 엔진은 실행하지 않는다. 사전 화면을 열거나 기간을 바꿀 때 한 번만 통계와 배치를 계산한 뒤 경량 SVG를 그림.
- 기록 편집 시에도 저장 자체가 최신 상태이므로 다음에 사전 탭을 열면 곧바로 반영된다.
