# 결. V31 — 6개월 ↔ 1년 전환 모션 개선

## 문제
V21~V30의 고밀도 전환은 오프스크린 작업을 줄이기 위해 이동 날짜 구슬을 76개로 제한하고, 새로운 레이아웃에서 추가할 날짜도 일부만 페이드했음. 나머지 날짜는 손을 놓는 순간 새 위치에 나타나 **점프/깜빡임**처럼 보일 수 있었음.

## 해결: 전체 레이어 페이드 + 핵심 날짜 이동의 하이브리드
- **6개월 ↔ 1년** 전환에만 적용. 1·3·6개월 사이의 기존 날짜별 FLIP은 유지.
- 현재 포스터의 전체 레이어 opacity는 `1-p`, 다음 포스터 레이어 opacity는 `p`. 전체 레이아웃을 1~2회 레이어 단위로 조정하므로 개별 날짜마다 불투명도를 갱신하지 않음.
- 손가락 중심과 가까우면서 전환 전후 화면에 보이는 같은 날짜를 **최대 48개(폭 좁은 모바일)** 선정. 각 날짜는 1회 복제한 구슬을 고정 오버레이에 놓아, 실제 두 날짜 위치·직경 사이로 `translate3d()/scale()` 이동. 큰 화면은 최대 60개.
- 이동시킬 날짜의 원본/대상은 복제 구슬과 겹쳐 보이지 않도록 임시로 숨김. 나머지 수백 개 날짜는 포스터 전체에 걸쳐 함께 페이드하므로 한꺼번에 '팝' 하는 날짜가 없음.
- 구슬 복제는 DOM 밖에서 한 번에 준비하고 붙여 레이아웃 강제 반복을 줄임.
- 추가 최적화: 날짜별 색상·동심원 내부원 HTML을 **달력 마크업 생성 시 직접 넣어** 렌더 후 365개 요소에 구슬을 다시 칠하던 DOM 순회를 제거. 복제 구슬의 날짜 글자 스타일도 원본 숨김 처리 전에 한꺼번에 읽음.
- 릴리즈 직후 다음 그리드를 활성화하면서 기존 그리드·새 그리드·구슬을 동일한 약 **230ms** easing으로 마무리. 릴리즈 시 진행률을 잃지 않으며, 다음 제스처 시작 시 남은 전환을 즉시 정리해 연속 줌을 허용.
- 한 손가락 수직 스와이프와 마우스 수직 드래그도 해당 구간에서 같은 하이브리드 전환(자동 360ms)을 사용.
- 사진 같은 큰 구슬 디자인, 동심원 1~4감정 규칙, 8가지 기본색, 구슬 숫자색은 변경하지 않음.

## 구현 및 안전
- `app.js`: `stagePoster`, `drawStage`의 poster-mode, `commitPosterStaged`, `clearPosterSettle`, `animateSwipeZoom`.
- `styles.css`: `zoom-poster-morph`, `zoom-poster-stage`, `zoom-old-layer`, `zoom-bead-overlay` 및 `zoom-bead-ghost`.
- 성능 상한: 터치 이동 중 최대 **48개 모바일 고스트 변환 + 2개 부모 opacity 값 + 헤더 2개 opacity 값**. 하이브리드 경로의 커밋 애니메이션도 compositor `opacity/transform` 기반.
- 데모와 사용자 실제 기록 모두 공유. `gyeol-v2` 저장 데이터·로컬 저장 로직은 그대로.
