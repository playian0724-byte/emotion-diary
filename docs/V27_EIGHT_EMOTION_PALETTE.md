# 결. V27 — 고정된 감정 8색과 레퍼런스 글자색

V26에서 색 카드의 12색을 무작위로 사용한 방식은 감정과 색의 고정된 관계를 흐렸음. V27은 옵션 A를 채택하여 **기본 감정은 8개 그대로** 유지하고 각 감정에 색/날짜 글자색을 1:1로 지정함.

## 구현
- `BASE`에 8개 감정 각각 `color` 및 `ink` 지정, `BASIC_PALETTE`로 빠른 조회.
- 기본 감정 선택, 구슬 저장, 색 혼합, 사전 및 날짜 기록에서 사용하는 색상은 이 `BASE` 하나를 참조. 샘플 개인 감정과 커스텀 감정 ID 구조는 그대로.
- 날짜가 기본 감정 하나면 그 감정에 매핑된 사진의 숫자색을 그대로 사용. 그라데이션은 미리 정한 8가지 기본 감정 조합별 글자색을 우선하며, 다른 조합 및 사용자 정의 감정 혼합은 동일 팔레트 글자색들 중 최소 대비가 가장 나은 색을 선택.
- 데모 `DEMO_PIGMENTS`는 현재 `BASE` 색에서 파생. 2026-01-01부터 오늘까지의 임의 구슬은 정확히 이 8색만 표시하며 새로운 색을 추가하지 않음.
- 기존 V26의 구슬 테두리 없음, 큰 1개월 구슬, 굵은 날짜 숫자와 V22~V21의 연속 핀치·제목 페이드 유지.
- 저장 포맷 `gyeol-v2` 수정 없음. 기존 기록은 감정 ID로 보관하므로 **기록이나 메모는 보존되지만 기존 기록의 표시색은 새 색으로 일괄 업데이트**. 데모 모드는 여전히 localStorage에 쓰지 않음.

## 사용성 주의
사용자가 지정한 사진의 글자색 조합을 그대로 따르기 때문에 일부 색상 조합(특히 노랑-하늘색)은 WCAG AA 대비 기준에 못 미칠 수 있음. 이 버전은 참고 사진에 충실한 디자인 시안이며 작은 연간 원에서 읽기 어려우면 대비만 별도로 조정해야 함.
