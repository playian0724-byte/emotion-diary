# 결. V17 — Gallery-like Continuous Archive Zoom

**목적:** V16까지는 핀치 배율이 임계값을 넘으면 달력 DOM이 즉시 재배열되어 이미지 갤러리보다 시각적으로 끊겼다. V17은 손가락을 따라 실시간 크기가 변하는 미리보기와 손을 놓은 뒤의 구슬별 부드러운 이동을 합친다.

## 제스처
1. iPhone Safari에서 두 손가락으로 핀치하면 **DOM 재렌더 없이 현재 구슬 포스터 자체를 손가락 중심으로 연속 확대/축소**한다.
2. 스케일 변화가 작으면 270ms 동안 원래 크기로 자연스럽게 되돌아간다.
3. 16% 이상 확대/축소하면 손을 놓을 때 인접한 보기(1↔3↔6↔12개월) 하나로 확정한다. 새로운 기간은 손가락 아래 가장 가까웠던 날짜가 포함된 달을 기준으로 정렬한다.
4. 기존 화면에서 보이던 날짜 구슬 위치를 캡처하고, 바뀐 레이아웃의 동일한 날짜까지 WAAPI **FLIP(First–Last–Invert–Play)** 방식으로 각각 480ms 이동 및 크기 보간한다.
5. 가능한 경우 스크롤 위치도 조절하여 손가락 아래에 있던 날짜가 새로운 화면에서도 비슷한 수직 위치에 남도록 한다.
6. 새롭게 보이는 구슬은 290ms 동안 서서히 나타나고, 헤더는 380ms 동안 가볍게 이동한다.
7. 한 손가락 드래그와 데스크톱의 Ctrl + 트랙패드 휠 제스처도 유지한다.
8. `prefers-reduced-motion` 사용자는 미리보기 및 개별 구슬 이동을 생략하며 뷰만 변경한다.

## 모바일 성능 및 안전성
- 핀치 `touchmove` 중에는 오직 상위 포스터 요소의 CSS transform만 변경하여 재배치/캔버스 계산을 하지 않는다.
- 새 구슬 배열로 전환할 때만 기존/새 구슬의 위치를 읽고, 화면에 가까운 구슬 **최대 105개**만 독립적으로 애니메이션한다.
- 1년 포스터에서는 가까운 날짜를 우선 정렬하여, 늦은 달도 자연스럽게 애니메이션되도록 한다.
- 드래그나 핀치 직후 가짜 클릭으로 날짜가 열리지 않도록 짧은 클릭 억제 시간을 둔다.
- 감정색, 원형 구슬, 기록 데이터 `gyeol-v2`, 혼합 시스템, 저장 시 날짜로 이동하는 구슬 애니메이션은 변경하지 않는다.
