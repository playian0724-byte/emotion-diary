# 결. — V15 Annual Bead Poster

기존 V14가 12개의 개별 월별 달력이었다면, V15의 연간 뷰는 **하나의 큰 연감 포스터**다. 사용자의 연감 디자인 레퍼런스처럼 달 표기는 굵은 숫자, 날짜는 촘촘한 원형 구슬로 표현한다.

## 보이는 요소
- 연간: 상단에 연도 숫자만 매우 크게 표시(예: `2026`).
- 아래에 열 12개 = 01~12월, 각 열 제목은 **굵은 두 자리 숫자**, 영어/한국어 월명 없음.
- 각 열에 1~28/29/30/31일까지의 원형 날짜를 세로로 쌓는다. 짝수 열은 약 반 칸 아래로 밀어 **구슬이 쌓인 듯한 지그재그**를 만든다.
- 기록 없는 날은 거의 배경과 같은 옅은 회색 원, 기록된 날은 감정 구슬 이미지. 날짜 숫자는 원 안에 표시한다.
- 연간 뷰에는 요일 행이 없고, 네모난 월별 카드도 없다.
- +/− 버튼과 제스처 안내문 제거. `년`, `월` 한글을 화면의 연월 라벨에서 제거.
- 이전/다음 기간의 화살표만 최소한으로 유지.
- 1·3·6개월 뷰는 7열 달력/요일을 유지하되 연월 라벨을 `2026 / 10`이나 굵은 `10`으로 숫자화한다.

## 조작과 데이터
- 기존 `1 → 3 → 6 → 12개월` 확대·축소를 핀치·드래그로 유지.
- 날짜 클릭 시 해당 날짜 메모·감정 표시.
- 저장 구슬이 해당 날짜의 `.mini`에 도착하는 애니메이션 유지.
- localStorage `gyeol-v2` 변경 없음. 감정 혼합과 사전 로직 그대로 둠.
- `index.html`, `app.js`, `styles.css`에 v15 캐시 버전 적용.
