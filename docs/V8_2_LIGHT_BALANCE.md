# 결. V8.2 — Light Balance

**상태:** WebGL2 실험 렌더러에 반영. 기존 V7 기본 모드 유지.

## 테스트
- V7/V8.2 비교: https://playian0724-byte.github.io/emotion-diary/compare.html
- V8.2 웹앱: https://playian0724-byte.github.io/emotion-diary/?renderer=webgl&v=8.2

## 튜닝
1. 구슬 경계 알파 전환 `smoothstep(.973,1.045,r)` → `smoothstep(.986,1.026,r)`, 흐림 폭 약 44% 감소.
2. 중심광 가우시안 반경 `(.21~.29, .20~.28)` → `(.25~.34, .24~.32)`, 중심광 영역 소폭 확대.
3. 중심광 광량 `(.27+.105*beat)` → `(.22+.075*beat)`, 빛의 점처럼 과도하게 밝던 부분 완화.
4. 주변 산란광 반경 `(.50~.67, .48~.63)` → `(.56~.71, .54~.69)`, 주변 영역을 더 넓게 밝힘.
5. 주변 산란광 광량 `(.16+.045*beat)` → `(.20+.055*beat)`, 중심과 주변의 명도 차 완화.
6. 후광 반경 `.36~.44` → `.30~.36`, 외부 감쇠 마스크 `1.57~1.85` → `1.44~1.72`로 축소.
7. 광원 위치 고정/동기화 박동, 색 조합에 따른 방향별 후광, V7 fallback 및 기존 저장 키 `gyeol-v2`는 유지.

**의도:** 더 선명한 경계, 넓지만 낮고 부드러운 내부 광원, 밝은 주변부, 이전보다 정돈된 작은 후광.
