# 결. V20 — 날짜 구슬이 각자의 다음 자리로 직접 이동

## 문제
이전 V18~V19는 전체 달력 레이어를 투명도로 교체해서, 같은 날짜 구슬이 실제로 자신의 다음 자리로 이동하지 않는 것처럼 보임.

## 변경
- 핀치 방향을 정하면 다음 보기(1/3/6/12개월)의 날짜 구슬을 미리 렌더링.
- 같은 날짜를 `YYYY-MM-DD`로 대응시켜 **현재 위치 및 지름과 다음 위치 및 지름을 측정**.
- 각 구슬의 `translate3d(x,y,0) scale(s)` 값을 핀치 진행률에 맞게 **개별적으로 갱신**. 같은 날짜는 움직이는 동안 같은 색과 숫자를 유지하며, 전체 달력에는 scale/opacity 변환을 적용하지 않음.
- 다음 보기에서 처음 등장하는 날짜만 원래 자리에서 점차 나타남. 다음 보기에서 빠지는 날짜는 차츰 사라짐. 공유 날짜는 절대 단순 크로스페이드하지 않음.
- 손을 떼면 약 410ms의 감속 애니메이션으로 각 구슬이 최종 자리에 정착.
- 최종 화면은 미리 준비한 DOM을 그대로 사용하며 날짜 클릭 이벤트 복원.
- 성능: 기존/새 좌표는 제스처 초기에 딱 한 번 측정. 이동 중에는 requestAnimationFrame에서 transform/opacity만 갱신. 화면 바깥 구슬에 대한 불필요한 개별 transform 계산 제한.
- V19의 기록 설명 즉시 숨김, 핀치 취소 시 복원, 날짜 재선택시 열기, 감정 혼합·저장 기능 및 localStorage `gyeol-v2` 유지.
- 시스템 Reduce Motion 선호는 별도의 즉시 단계 전환 사용.
