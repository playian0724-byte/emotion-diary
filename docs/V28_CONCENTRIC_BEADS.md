# 결. V28 — 여러 감정을 표현하는 겹원 구슬

## 디자인 규칙

1. **1색:** 감정의 고정 대표색으로 꽉 찬 단색 원.
2. **2색:** 첫 번째로 선택한 감정을 **내부원**, 두 번째 감정을 **바깥 링**으로 표현. 예를 들면 내부 노란 기쁨, 바깥 빨간 분노.
3. **3색:** 첫 번째 감정을 내부원에 채우고, 바깥 링은 두 번째·세 번째 색으로 **좌우 이등분**.
4. **4색:** 내부원은 첫 번째·두 번째 감정색으로 **좌우 이등분**, 바깥 링은 세 번째·네 번째 감정색으로 **좌우 이등분**.

동심원 내부 지름은 전체 구슬 지름의 **69%**. 따라서 바깥 링 두께는 지름의 약 15.5%. 내부원과 바깥 링의 경계는 선명하고, 색이 흐릿하게 섞이지 않음. 감정 순서는 사용자가 선택한 순서를 보존.

## 적용 대상
- 오늘 감정 선택 미리보기 `#today-orb`
- 실제/데모 기록의 1·3·6·12개월 날짜 구슬
- 핀치 중 생성되는 다음 단계 날짜 미리보기
- 오늘의 구슬이 날짜로 이동하는 저장 애니메이션
- 감정 숫자색은 **내부원** 기준. 4색의 경우 내부 2색과 모두 대비되는 고정 팔레트 글자색을 선택.

구현은 가벼운 CSS 배경·추가 `.orb-center` 요소를 사용해 색을 겹쳐 표현하며 복잡한 그라데이션 Canvas 연산을 하지 않음. 전체 달력/감정 사전/날짜 선택/저장 형식 `gyeol-v2`는 유지. 내 감정 사전에서 만든 커스텀 색상도 같은 방식으로 구슬에 표시.

## 샘플 기록
- `demo=1`에서 1월부터 오늘까지 단색 70%, 다중감정 30% 비율 유지.
- 데모의 다중감정 기록에 2색·3색·4색 조합을 섞어 실제 앱의 동심원 디자인을 비교할 수 있도록 함.
- 데모에서 실제 저장 데이터에 기록하지 않음.
