# V14 Nordic emotion calendar

목표: 기록을 읽는 방식 자체를 디자인한다. 원색 구슬 위에 날짜 숫자를 올리고, 맨 윗줄에는 요일을 배치한다. 밝은 아이보리 배경과 규칙적인 그리드를 사용하는 절제된 북유럽 모던 감성.

## 기간
- 1개월: 기본 주간 달력, 큰 감정색 원 위에 날짜 표시
- 3개월: 분기별 세 달, 각 달의 요일 표시
- 6개월: 반년, 모바일에서도 2열 카드 없는 그리드로 밀도 증가
- 1년: 1월~12월, 2열×6줄 월별 미니 달력
- 확대/축소 시 분기, 반기, 연 단위 경계로 정렬
- 좌우 기간 이동은 현재 선택된 길이만큼 이동

## 조작
- 핀치 아웃: 확대(12→6→3→1개월)
- 핀치 인: 축소(1→3→6→12개월)
- 달력의 한 손가락 수직 드래그: 기간 단계 변경, 수평 드래그: 이전/다음 기간
- iOS Safari를 위해 두 손가락 touchmove 처리 추가. 한 손가락 페이지 스크롤은 기본 허용
- 확대·축소 컨트롤에서 위/아래로 드래그하거나 +/- 버튼을 사용해도 동일한 기능
- 날짜 탭 시 선택 날짜와 메모 표시
- 날짜의 글자는 원형의 상대 명도에 따라 밝거나 어두운 잉크로 자동 선택

## 회귀
- 오늘 저장 시 비행하는 구슬의 착지 대상은 기존 `.mini` 유지
- `gyeol-v2` 로컬 기록과 감정 사전 변경 없음
- 기본 원색 구슬 렌더러와 V8 광원 실험은 변경 없음
