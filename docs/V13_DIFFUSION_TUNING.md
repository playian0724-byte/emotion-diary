# 결. V13 — 느리고 멀리 번지는 물감

## 사용자 피드백
1. 길게 누르면 방울 수가 너무 빨리 늘어나 미세 조정이 어렵다.
2. 떨어진 감정색이 너무 빨리 멈춘다. 더 천천히 넓게 퍼지며 혼합 박스 가장자리까지 닿기를 원한다.

## 변경 사항
- 기본 감정 선택 UI는 V8의 색상 원 버튼 그대로 유지.
- 탭 1회 = 1방울은 이전과 동일.
- 길게 누르기: 누르는 즉시 1방울 추가, **780ms 후 두 번째 방울**, 그다음 **850ms마다 1방울**. 이전 230ms 간격보다 차분하게 비율을 미세 조정할 수 있다.
- 각 방울의 확산 진행시간 **0.95초 → 2.8초**. 확산의 속도를 부드러운 easing으로 제어.
- 확산 Gaussian 반경 **최대 84px → 화면 크기에 따라 최대 약 195px**. 밝은 색의 가장자리가 박스의 바깥까지 닿도록 분포 곡선을 완만하게 변경.
- 파문 진행 **1.15초 → 2.2초**, 최대 반경 **39px → 74px**. 색이 수면 전체로 천천히 번지는 인상.
- 섞기 시작 시 방울 확산의 나이를 고정하여, 기존 V10의 **중앙 응집** 중 확산과 수축이 충돌하지 않게 함.
- 많은 방울이 있을 때 렌더링 간격을 조정해 모바일 부하 완화.
- 감정 저장·사전·오늘·달력·원색 구슬 및 localStorage `gyeol-v2` 변경 없음.
