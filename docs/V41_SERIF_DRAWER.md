# 결. V41 — 명조 타이포그래피 / 우측 슬라이드 메뉴

## 원칙
기존 결.의 기록과 구슬 색상·렌더링·감정 혼합·아카이브·감정 지도·유통기한은 그대로. 네비게이션과 일부 헤딩 타이포그래피만 변경.

## 부크크 명조 느낌
정식 부크크 명조를 설치/배포하지 않고, 인쇄물 스타일에 가까운 Noto Serif KR 400–700 Google Fonts 서체를 화면 대제목/소제목/사전 감정명에 적용. 오프라인/외부 폰트 로드 실패 시 Nanum Myeongjo, AppleMyungjo, Batang, serif로 대체. 일반 버튼과 구슬 안의 텍스트는 가독성 좋은 기존 시스템 고딕 유지.

## 슬라이드 메뉴
V40 하단 4분할 아일랜드 대신 우측 상단 3개 가로선 버튼. 누르면 화면 오른쪽에서 최대 340px 너비 서랍이 380ms의 완만한 커브로 슬라이드 인. 화면 바깥에는 24% 딤 레이어. 메뉴 버튼의 선이 X로 변환되며 터치 및 키보드 Esc로 닫기. 바깥 영역 클릭 시 닫고, 페이지 이동 시 자동으로 닫힘. 메뉴 안에서 Tab/Shift+Tab 순환. reduced-motion 설정을 따름.

## 유지
- 감정색 8종, 구슬 색깔 혼합, 동심원, 구슬/달력 색 변경 없음
- 오늘, 기록, 사전, 마이, 설정 화면 유지
- 기록 유통기한 설정과 1·3·6·12개월 핀치 동작 유지
- 마이의 진하기 다른 점선 감정 지도 유지
- 기존 gyeol-v2 로컬 기록 보존
