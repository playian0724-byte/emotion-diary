# 결. V19 — 하나의 고정 축과 기록 설명의 분리

## 요청
- 축소할 때 날짜 아래 기록 설명이 구슬과 함께 작아지거나 흐려지면 안 됨. 설명은 사라졌다가 해당 날짜를 탭하면 다시 열려야 함.
- 확대·축소할 때 오른쪽 상단과 하단 두 방향으로 끌리는 움직임을 없애고, 한 가지 안정된 축을 사용해야 함.

## 변경
1. `record-detail`은 초기에는 숨김. 날짜를 클릭하면 기록을 표시.
2. 핀치 시작 시 기록 설명 영역은 **즉시 숨김**. scale/opacity를 적용하는 구슬 필드와 구분함.
3. 핀치 취소(배율 임계치 미달)이면 이전에 열어둔 설명을 복원함.
4. 정상적으로 확대·축소를 완료하면 설명은 숨겨진 채로 둠. 다시 날짜를 누르면 표시.
5. 기존 outgoing .poster-months와 incoming .zoom-next-layer를 모두 **상단 중앙(50% 0%)**에 고정. 손가락 중앙이 이동해도 새 축을 만들지 않음.
6. 기존 V18의 stage.alignX/Y 이동값과 스크롤 위치 강제 보정 제거. 축소 도중 레이어 둘이 서로 다른 방향으로 미끄러지지 않도록 함.
7. 1·3·6·12개월 지그재그 구슬, 핀치 중 새 날짜 조기 등장, 색상과 `gyeol-v2` 기록 및 감정 혼합 유지.
