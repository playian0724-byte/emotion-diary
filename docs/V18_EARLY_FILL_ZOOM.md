# V18 — 연속적으로 여백이 채워지는 구슬 아카이브

사용자 피드백: V17은 축소할 때 구슬이 줄어든 자리에 빈 여백이 생기고, 손을 놓으면 주변 날짜가 갑자기 들어온다. 아이폰 갤러리처럼 움직이는 중부터 주변 날짜가 자연스럽게 들어와야 한다.

## V18 구현 방식
- 핀치 이동이 시작되면 현재 뷰의 다음 단계(1/3/6/12개월)를 **미리 렌더링하여 독립된 형제 레이어로 배치**.
- 기존 구슬 필드는 손가락 중심에서 실시간으로 작아지고, 새 레이어는 동일한 감정색과 날짜를 유지한 채 서서히 선명해지며 여백을 채운다.
- 새 레이어는 현재 달력과 CSS 레이아웃을 공유하지 않으므로 서로 다른 1·3·6·12개월의 열 수가 충돌하지 않는다.
- 손을 놓을 때까지 새 날짜들을 기다렸다가 그리는 게 아니라, **핀치 도중 투명도와 위치가 연속 변화**한다. 축소 초기부터 새 구슬이 보이도록 easing을 조정했다.
- 손을 놓으면 약 310ms 동안 두 레이어가 마지막 자리로 정렬. 이미 보이고 있던 다음 단계의 DOM 요소 자체를 최종 달력으로 옮겨 사용한다. 최종 순간 재렌더링·재색상 계산 없음.
- 기준 날짜가 급격히 튀지 않도록 세로 스크롤 보정도 같은 310ms 동안 분배.
- 12% 미만의 작은 핀치는 220ms 동안 천천히 원래 크기로 복원.
- Reduce Motion에서는 복잡한 동작 없이 기존 단계 전환.
- 휠+Ctrl 기반 데스크톱 트랙패드 핀치, 저장, 감정 혼합, `gyeol-v2` 데이터 유지.
