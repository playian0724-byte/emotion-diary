# 결. V10 — 한 장의 Canvas에서 응집되는 감정

**상태:** GitHub Pages 기본 앱에 반영. 이전 V9의 단색 구슬·그라데이션 디자인 유지.

## 목표
물 위에 넓게 퍼진 감정 색이 가운데로 모여 **동일한 색 물질 그대로** 하나의 새 단색 구슬이 된다. 별도 구슬의 fade-in, 크기 확대, 아래에서 올라오는 효과는 쓰지 않는다.

## 구현
- 기존 `#mixed-orb` DOM 요소를 제거했다.
- `#water-canvas`가 퍼진 물감, 응집 중 색, 최종 구슬을 **처음부터 끝까지 모두 그린다.**
- 색 물감 방울들을 원본 감정별로 그룹화해 위치와 방울 개수를 계산한다(동시에 최대 8색).
- 화면에 보이지 않는 작은 계산용 buffer에 한 프레임의 픽셀 색상 필드를 생성한다. 표시용 Canvas는 오직 1개다.
- 원래 퍼진 색 부분의 농도 필드가 중심으로 수축하고, 같은 색 필드의 혼합 색과 알파가 연속적으로 변화한다. 별도 완성 구슬을 얹는 방식이 아니다.
- 응집 후에는 중앙에 직경 약 146px의 **원색 단색 구슬**이 같은 Canvas 안에 남는다.
- 약 1.9초에 걸쳐 이동·색 혼합·윤곽 정돈. 완료 시 기존 혼합 비율과 저장/오늘 사용 폼이 표시된다.
- 화면 전환, 다시 만들기, 방울 빼기, 저장 데이터 로직을 유지한다. `prefers-reduced-motion` 사용자는 애니메이션을 생략한다.
- 외부 광원/반짝임/후광은 추가하지 않았다.

## 성능
- 계산용 Canvas는 너비 최대 250px, 감정 그룹은 최대 8개로 유지.
- 화면에 표시되는 큰 Canvas와 내부 계산용 buffer는 별도 역할이지만 DOM에서 겹친 레이어는 없다.
- 애니메이션 중 약 30fps로 업데이트하고, 완료 시 중지한다.
- 화면에서 벗어나면 `requestAnimationFrame` 중지.
