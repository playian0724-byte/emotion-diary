# V30 — 4감정 바깥 링의 좌우 대칭

V29에서는 세 색 분할선이 약 30° 기울어져 보였음. V30은 4감정의 3분할 링 시작 각도를 `-90deg`에서 `-60deg`로 회전.

- 첫 번째 바깥 색상 조각은 12시 방향을 기준으로 좌우 대칭
- 세 경계선: -60°, 60°, 180°
- 아래쪽 중앙의 분할선은 정확하게 6시 방향의 수직선
- 각 바깥 조각은 120°씩 동일
- 내부 원은 언제나 첫 감정의 단색
- 2감정 단색 링, 3감정 반반 링, 내부 지름 62% 유지
- 기존 기록과 `gyeol-v2` 저장 포맷, 동작·핀치 확대축소 유지
