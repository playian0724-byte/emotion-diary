# 결. V40 — 4분할 하단 아일랜드 / 유통기한 / 점선 지도

## 디자인
상단 결. 워드마크와 5개 탭 메뉴를 제거하고, 화면 아래 필렛 사각형 아일랜드로 4개 탭(오늘, 기록, 사전, 마이)을 4등분. 새 배경은 매우 옅은 크림색 #FDFCF8.
설정은 삭제하지 않고 마이 우상단 톱니바퀴로 이동. 설정 화면의 마이로 돌아가기 버튼과 직접 URL ?view=settings도 유지. 구슬·원 크기·색·동심원과 기존 주요 화면 구성은 그대로.

## 기록 유통기한
기존에는 선택 슬라이더의 input 이벤트가 표시만 바꾸고 change 이벤트가 와야 저장했기 때문에, 모바일에서 조작 후 바로 이동하면 유통기한 설정이 실제로 저장되지 않을 수 있었음.
이제 input 이벤트에서 바로 localStorage에 시간을 저장하고, 네 개의 점은 각각 42px짜리 선택 버튼으로 만들어 누르면 즉시 저장됨. 1시간 / 24시간 / 3일 / 7일만 허용하며 기본값 24시간.
저장에 실패하면 원래 설정으로 돌아가고 알림을 표시. 최초 기록 createdAt을 수정하더라도 만료 시각은 연장되지 않음. 날짜만 있는 옛 기록은 해당 날짜의 23:59:59.999를 기준으로 계산.
페이지가 다시 표시되거나 30초가 흐르면 잠금 UI를 갱신. 저장 동작과 기록 편집 시각 검사도 별도로 계속 수행. 로컬 데이터 키 gyeol-v2 및 기존 기록 유지.

## 감정 지도
관계선은 모두 두께 2.2의 작은 점선(stroke-dasharray 1 7)으로 변경. 관계 강도는 불투명도만으로 표현하며, 모든 노드 색상·크기·위치와 기간 선택·연결 데이터는 그대로.
