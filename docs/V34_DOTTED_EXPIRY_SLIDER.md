# 결. V34 — 네 점 슬라이더

## 방향

설정에서 기존 드롭다운을 없애고, **네 개의 작은 원이 가로로 놓인 범위 슬라이더**로 교체.

- 1시간 / **24시간 (기본)** / 3일 / 7일
- 바는 2px 얇은 중립 녹회색, 선택 구간만 저채도 짙은 그린
- 네 개의 작은 원은 바 위에 일정 간격으로 배치; 선택된 구간의 손잡이는 부드러운 아이보리 테두리를 가진 조금 큰 원
- 선택 값은 수치 타이포그래피로 가볍게 보여줌
- 기본 페이지의 무광 아이보리·코펜하겐/북유럽 모던 서체와 동일
- 새 창이나 확인 모달 없이 슬라이더 조작이 즉시 반영됨

## 입력 동작 및 저장

`<input type="range" min="0" max="3" step="1">` 사용. 네 단계는 균등 거리로 놓이고, 실제 저장 값은 `EDIT_EXPIRY_OPTIONS[index]`에 있는 **시간 수치**(1, 24, 72, 168)임. 기존 기록과 `gyeol-v2.settings.editExpiryHours` 호환.

- **input** 이벤트: 선택 표시, 라벨, 안내문, ARIA 값 즉시 갱신
- **change** 이벤트: 기간 설정 저장 및 화면 수정 기한 갱신
- 터치 탭/드래그와 키보드 화살표 조작은 브라우저 기본 `range`를 사용
- 데모 모드에서는 비활성화하며 기존 저장 데이터에는 접근하지 않음
- 과거 기록에 대한 소급 적용, 기한 도래 시 읽기 전용, 수정할 때 최초 생성 시각 유지 모두 변경 없음
