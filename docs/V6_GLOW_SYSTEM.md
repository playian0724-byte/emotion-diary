# 결. V6 — 빛을 품은 색유리 구슬

상태: GitHub Pages용 프로토타입 구현 완료, 아이폰 Safari 실기기 사용자 확인 대기.

## 레퍼런스와 디자인 의도
인사이드 아웃의 감정 구슬 이미지처럼, **얇은 색유리 표면 안쪽에서 빛이 일어나고 그 빛이 밖으로 살짝 번지는 모습**을 목표로 한다. 현실적인 3D 광학 시뮬레이션이나 실제 영화 이미지 복제가 아니라, 사진/영상의 분위기를 해석한 2D Canvas 렌더링이다.

- 기존 V5의 차가운 자연광 구체 → V6의 따뜻한 내부 발광 구체.
- 구슬 바깥으로 새는 빛은 색과 일치하고 절대 네온처럼 강하지 않게.
- 테두리·임의의 흰색 림·스티커 같은 하이라이트 없음.
- 구슬을 제외한 앱 화면은 미니멀한 무채색 디자인 유지.

## 구현
### 1) 구슬 텍스처: app.js
- orbStyleForColors()에서 224×224 픽셀 RGBA Canvas 텍스처 생성, 색 조합별 메모리 캐시.
- 표면 방향성 확산광, 중심 내부 발광, 작고 흐릿한 반사, 큰 단위의 은은한 색결을 한 렌더링 패스로 합성.
- 투명한 색유리의 인상을 주되 구 내부에는 과한 투명도를 적용하지 않음. 배경에 따라 감정색이 옅어지는 문제를 방지.
- 외곽에는 픽셀 안티앨리어싱만 적용하며 새로운 색 테두리를 만들지 않음.
- 다색 구슬과 새로 만든 단색 감정의 결과 구슬이 같은 렌더러 사용.

### 2) 감정색 영역 확대
오늘 기록의 다색 구슬과 감정 혼합 실험실의 단색 결과는 서로 별개의 개념이다.

- 1개: 단색.
- 2개: 서로 마주 보는 방향에서 부드럽게 이어지되 전이 구간만 약하게 축소.
- 3개: 원을 내접원으로 하는 정삼각형 세 꼭짓점 색을 유지. 비율 지수 1.48로 꼭짓점 감정의 존재감 조금 확대.
- 4개: 원을 내접원으로 하는 정사각형 네 꼭짓점 색 유지. 비율 지수 1.48로 꼭짓점 감정의 존재감 조금 확대.
- 모든 색은 **하루에 공존한 감정들**이며, 색의 공간 분포가 정확한 감정 비율을 나타내는 것은 아님.
- 실험실에서 만든 **새 감정**은 기본 감정 혼합 비율을 통해 단색이 되는 기존 동작 유지.

### 3) 바깥 Halo 및 미세한 호흡: styles.css
- pigment 평균의 색에 기반한 아주 약한 rgba 빛을 box-shadow로 표현.
- 오늘의 큰 구슬과 감정 혼합 결과 구슬에 6.2초 주기의 미세한 밝기 변화 및 halo 확장.
- 달력 속 작은 구슬은 애니메이션 없이 훨씬 약한 정적인 후광만 적용.
- 저장 중 날아가는 구슬에는 호흡 애니메이션을 중지하여 이동 동작을 유지.
- prefers-reduced-motion을 켠 사용자에게 반복 애니메이션을 제공하지 않음.

### 4) 개인정보와 기존 기록
- localStorage 키 gyeol-v2 그대로 사용.
- 기존 날짜, 메모, 직접 만든 감정 이름/정의/색상은 변경하지 않음.
- 현재 GitHub Pages는 서버 동기화가 없으며, 브라우저 데이터 삭제 시 기록이 사라질 수 있음.

## QA 체크리스트
- [ ] 큰 구슬이 안쪽에서 은은하게 빛나는 느낌인지, 과장된 네온처럼 보이지 않는지
- [ ] 빛이 구슬 밖으로 아주 약하게 새어 나오는지
- [ ] 2색의 전이 영역이 V5보다 조금 줄었는지
- [ ] 3/4색에서 삼각형·사각형 꼭짓점 색이 더 확실한지
- [ ] 구슬의 원형 외곽에 다른 색의 테두리가 생기지 않는지
- [ ] 달력 작은 구슬이 흔들리거나 지나치게 발광하지 않는지
- [ ] 새 감정 혼합 완료 결과도 같은 조명 질감인지
- [ ] 오늘 저장 애니메이션과 기존 기록/사전 데이터가 정상인지
- [ ] Reduce Motion 환경에서 반복적인 발광 애니메이션이 중지되는지
- [ ] 아이폰 Safari에서 터치 입력과 성능에 문제 없는지
