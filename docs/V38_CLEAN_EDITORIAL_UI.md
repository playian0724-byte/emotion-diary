# 결. V38 — 안내 문구를 줄인 미니멀 UI

## 디자인 방향

작고 회색인 "이렇게 해보세요" 형태의 설명문을 화면마다 반복하지 않도록 정리. 무광 아이보리, 고정 감정 8색, 코펜하겐 모던 타이포그래피는 유지. 설명 대신 **제목·구슬·지도·조작 버튼** 자체로 이해되는 화면을 목표로 함.

## 변경
- **오늘:** 선택 전 "감정을 선택하세요." 카피 제거. 선택한 감정 이름·현재 날짜는 유지. 불필요한 "선택" 보조 라벨 및 메모 입력 placeholder 제거.
- **기록:** 기록 아카이브는 그대로. 샘플 미리보기 배너만 간결하게 "샘플"로 축약.
- **사전:** 소개 문장, "Private" 중복 뱃지, 기기에만 저장된다는 하단 설명 제거. 감정 정의·사용 버튼·새 감정 만들기는 유지.
- **마이:** "기록이 쌓이면서…" 부제목 및 지도 크기·선 굵기 설명, 중복 섹션 타이틀 제거. "나의 지도", 전체/30일 토글, 지도, 실제 기록 통계를 표시. 지도 높이를 조금 더 키움.
- **설정:** 안내 문장, 중복 상태 문단 및 유통기한 부연 설명을 화면에서 제거. 유통기한 제목·24시간 등 현재 선택값·4점 슬라이더만 전면 배치. 화면 읽기 도구에는 만료 안내를 비시각적 설명으로 제공.
- **새 감정 만들기:** "색을 섞어보세요", "탭 · 길게 누르기", 미입력시 저장 가능 안내, 선택형 보조 문구를 제거. 실제로 색을 추가할 때 **n방울**, 혼합 비율, 혼합 완료 등의 상태만 표시.
- **기록 수정:** 감정 최대 4개 등 불필요한 설명을 제거. 유통기한이 지난 경우의 읽기 전용 정보는 유지.

## 유지해야 할 정보
- 날짜·기록 감정·사용자가 작성한 정의/메모·실제 빈도·최근 30일 기간·유통기한 표시
- 실수 방지를 위한 필수 알림(저장 실패, 기록 잠금, 한계값)
- 접근성을 위한 폼 레이블 및 화면 읽기 도구 상태 설명
- 기존 로컬 저장 키 \`gyeol-v2\`, 변경 없는 기록 내용 및 데모 격리
- 1~4개 감정 링, 핀치 줌, 감정 지도 배치, 유통기한 저장 기능
