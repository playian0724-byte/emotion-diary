# V64 — Quiet Object Stack

This version changes only the experimental 7-day Stack under `?view=weekdemo`.

- Default: weekday/date only at left; emotions are hidden.
- Active: single bead grows with existing transition and emotion caption / optional one- or two-line sample memo fades into the **same fixed-height row**.
- Stable column for right-aligned beads, no background card/filled active highlight.
- Week arrows, simulated age zoom restriction, week/month and month/quarter/half/year pinch remain unchanged.
- Sample notes and moods are deterministic and in-memory only. Actual `gyeol-v2` localStorage records are not modified.
- Demo initial week on 2026-11-01 has five recorded and two unrecorded dates.
