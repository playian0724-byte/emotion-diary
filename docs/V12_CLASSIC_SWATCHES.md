# 결. V12 — V8의 원래 감정 선택 UI 복구

## 변경
- V11에서 임의로 넣었던 스포이드 그림(감정 버튼 안 SVG)을 **완전히 제거**.
- 수면 위로 내려오는 별도의 스포이드 UI 및 등장/낙하 애니메이션 **완전히 제거**.
- V8에서 쓰던 **작은 원색 동그라미 + 감정 이름 + 방울 개수** 버튼을 복원.
- 감정 버튼을 누르자마자 수면에 잉크가 떨어져, 각 방울의 위치에서 점차 확산되고 옅은 파문이 일어남.
- 탭 및 길게 누르기(반복 방울 추가), 방울 빼기, 다시 만들기 유지.
- 섞기를 누르면 **V10의 단일 Canvas 응집**을 유지. 다른 구슬이 별도 등장하지 않음.
- 오늘 기록, 개인 사전, 기록 데이터(`gyeol-v2`), 기본 원색 디자인 유지.
